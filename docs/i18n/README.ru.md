Инструмент голосового дубляжа видео на базе искусственного интеллекта, который автоматически расшифровывает, переводит и повторно дублирует видео на 26 языков, с опциями локальной обработки и без ключей API, требуемых по умолчанию. Распознавание речи Whisper выполняется локально; Edge-TTS, Google Translate и DeepL требуют подключения к Интернету. Дополнительные функции (DeepL, идентификация говорящих (диаризация)) могут потребовать ключ API или токен доступа.

> **v2.0** - модульный пакет, локальный перевод Ollama, оркестровка профилей качества, устанавливаемые метаданные Python и дополнительные интеграционные тесты с реальными моделями. Полный список изменений см. в [GitHub Releases](https://github.com/HeartB1t/VideoTranslatorAI/releases) и истории коммитов.

## Как это работает

1. **Транскрипция** - [faster-Whisper](https://github.com/SYSTRAN/faster-whisper) транскрибирует звук (с ускорением графического процессора).
2. **Разделение голоса и музыки** - [Demucs](https://github.com/facebookresearch/demucs) изолирует вокал от фоновой музыки.
3. **Перевод** - MarianMT (локальный, офлайн), Google Translate, DeepL Free или **Ollama LLM** (Qwen3, краткие переводы с учетом слотов)
4. **идентификация говорящих (диаризация)** *(необязательно)* - [pyannote-audio](https://github.com/pyannote/pyannote-audio) определяет, кто говорит в каждом сегменте
5. **голосовое дубляж** - [Edge-TTS](https://github.com/rany2/edge-tts) (более 400 голосов) или [Coqui XTTS v2](https://github.com/coqui-ai/TTS) (клонирование голоса для каждого говорящего в разговоре)
6. **Микширование** - дублированный голос смешивается с оригинальной фоновой музыкой.
7. **Нормализация** - окончательный звук нормализуется до -23 LUFS (стандарт вещания EBU R128)
8. **Синхронизация губ** *(опционально)* - [Wav2Lip](https://github.com/Rudrabha/Wav2Lip) синхронизирует движения рта с дублированным звуком.

## Особенности

- 🖥️ Тематический графический интерфейс (Tkinter) - командная строка не требуется; Темы Graphite, Slate, Light и Neon, цвета акцентов, размер текста и панели настроек, порядок которых можно изменить путем перетаскивания.
- 🌍 **26 целевых языков** с несколькими голосами на каждом языке
- 🌐 **Интерфейс на 26 языках** - сам интерфейс адаптируется под ваш язык
- 🎬 **Поддержка YouTube и URL** - вставьте любую ссылку YouTube и переведите напрямую (на базе yt-dlp)
- ▶️ **Встроенный видеоплеер** (libmpv/mpv) - элементы управления транспортировкой с цветовой кодировкой, список воспроизведения, оригинальный звук A/B или дублированный, переключение субтитров, снимок, полноэкранный режим, открытая папка
- ⏱️ **Перевод в реальном времени** - смотрите локальный файл или разрешенную ссылку на видео по запросу с переведенными субтитрами и ползунком задержки в стиле YouTube; движки MarianMT/Google/DeepL/Ollama. В экспериментальной озвучке используется Edge-TTS и второй экземпляр mpv. Обработка наложения голосов и прием реального звука/Windows продолжаются; растущие прямые трансляции пока не поддерживаются. См. [статус текущей реализации](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).
- 🎵 Разделение голоса и музыки через Demucs (сохраняет фоновую музыку)
- 🔇 **Отключение оригинального звука**, доступное до и во время трансляции в реальном времени, отключает звуковую дорожку видео, сохраняя при этом переведенный голос слышимым. Выключите его, чтобы восстановить исходный звук; он сбрасывается, когда заканчивается сеанс реального времени.
- 🧠 **MarianMT** - полностью локальный автономный нейронный перевод (Helsinki-NLP, без ограничений по скорости запросов, без ключа API)
- 🤖 **Перевод Ollama LLM** *(новое в версии 2.0)* - локальный LLM (Qwen3, Llama, Mistral), создающий краткие переводы с учетом слотов для естественного голосового дубляжа, автоматически обнаруживает/устанавливает/запускает/извлекает модель при первом использовании
- 🎙️ **Клонирование голоса** - Coqui XTTS v2 клонирует человека, говорящего голосом исходного аудио на целевом языке (модель ~1,8 ГБ), с адаптивной скоростью для каждого сегмента и многократным повтором попыток при галлюцинациях.
- 👥 **идентификация говорящих (диаризация)** - pyannote-audio 3.1 идентифицирует говорящих нескольких человек; XTTS клонирует каждый голос отдельно
- 💋 **Lip Sync** - Wav2Lip GAN синхронизирует движения рта с дублированным звуком (модель ~416 МБ)
- 🔊 **Нормализация звука** - автоматическая нормализация громкости -23 LUFS (EBU R128)
- ✏️ Редактор субтитров: просмотрите и исправьте субтитры перед озвучиванием.
- 📦 Пакетная обработка - переводите несколько видео или URL-адресов одновременно
- ⚡ Ускорение графического процессора с помощью CUDA (автоматический возврат к процессору)
- 📄 Дополнительный экспорт субтитров `.srt`.
- 🔁 **DeepL Free** механизм перевода (необязательно - 500 тыс. символов в месяц, требуется бесплатный ключ API)
- 🔧 **Автоустановка** - отсутствующие пакеты Python и ffmpeg устанавливаются автоматически при первом запуске.

## Голосовой каталог

Голосовой каталог Edge-TTS определен в `LANGUAGES` в верхней части `video_translator_gui.py`. Этот словарь является источником истины для названий целевых языков, голосовых переключателей графического интерфейса пользователя и резервного голоса CLI, когда `--voice` опущен.

Примечания по техническому обслуживанию Клода/проекта отражают это место в `CLAUDE.md` под **Voice Catalog Source Of Truth**, поэтому будущие агенты кода знают, где обновлять голоса и куда README указывает пользователям.

## Системы перевода

| Двигатель | Настройка | Пределы | Качество |
|--------|-------|--------|---------|
| **Google Translate** *(по умолчанию)* | Нет | Неофициальный парсинг - может быть ограничен для больших видео. | ★★★★ |
| **MarianMT** | Нет - загружается ~298 МБ на каждую языковую пару при первом использовании. | Нет - полностью отключен от сети после загрузки | ★★★★ |
| **DeepL Free** | Бесплатный ключ API на [deepl.com](https://www.deepl.com/pro-api) | 500 тыс. символов/месяц | ★★★★★ |
| **Ollama LLM** *(рекомендуется для озвучивания - новое в версии 2.0)* | Устанавливается автоматически при первом использовании (модель Ollama ~1 ГБ + 5 ГБ) | Нет - полностью локально | ★★★★★ |

> **MarianMT** использует модели [Helsinki-NLP/opus-mt](https://huggingface.co/Helsinki-NLP), кэшированные локально после первой загрузки. Требуется явный исходный язык (автоопределение не поддерживается - выберите исходный язык вручную). Необходимые пакеты Python (`sacremoses`, `sentencepiece`) устанавливаются автоматически при первом выборе, если они отсутствуют.

> **Ollama LLM** *(новое в версии 2.0)* - рекомендуемая система для голосового дубляжа, поскольку она производит переводы с учетом целевого временного интервала. В то время как MarianMT переводит буквально и производит итальянский/испанский/французский язык примерно на 25% дольше, чем английский (принудительно сжимая звук в TTS), LLM предлагается сохранять каждый сегмент кратким и естественным для устной речи, достигая типичного соотношения символов 0,85-0,95 по сравнению с исходным текстом. Модель по умолчанию - `qwen3:8b` (5,2 ГБ на диске, ~6 ГБ видеопамяти); `qwen3:4b` (~3 ГБ) - облегченный вариант, `qwen3:14b` - более качественный. Конвейер автоматически обнаруживает двоичный файл Ollama, автоматически устанавливает его через официальный установщик при первом использовании (со всплывающим окном согласия), запускает демон и извлекает выбранную модель - ручная настройка не требуется. Автоматически переключается на Google Translate, если чего-то не хватает.

## Клонирование голоса (XTTS v2)

Если эта функция включена, приложение извлекает голос говорящего из исходного видео и использует его в качестве эталона для клонирования голоса на целевом языке.

- Поддерживаемые языки: AR, ZH, CS, DE, EN, ES, FR, HI, HU, IT, JA, KO, NL, PL, PT, RU, TR (17/26)
- Для остальных 9 языков Edge-TTS используется автоматически в качестве резервного варианта.
- Модель (~1,8 ГБ) загружается автоматически при первом использовании на `~/.local/share/tts/`.
- **Эталон с фильтром VAD** (v1.4): 10-15 секунд непрерывной речи, выбранной из исходного звука с помощью [silero-vad](https://github.com/snakers4/silero-vad) для лучшего качества клонирования голоса.
- **Скорость генерации** настраивается (`xtts_speed`, по умолчанию `1.25`): более высокие значения уменьшают артефакты сжатия звука при постобработке, когда переведенный текст длиннее исходного слота. Настройка через `~/.config/videotranslatorai/config.json` или CLI `--xtts-speed`.
- Работает на CUDA или CPU

## идентификация говорящих (диаризация) (pyannote-audio)

Если эта функция включена, приложение определяет, кто говорит в каждом сегменте. В сочетании с клонированием голоса голос каждого говорящего клонируется отдельно - идеально подходит для интервью, подкастов и видеороликов с участием нескольких человек.

- Требуется бесплатный [токен HuggingFace](https://huggingface.co/settings/tokens) (однократная регистрация).
- **Токен надежно хранится** (v1.4) через связку ключей ОС: Windows Credential Manager, macOS Keychain, Linux Secret Service. Автоматическая миграция из предыдущего хранилища открытого текста JSON
- После первой загрузки работает полностью в автономном режиме.
- Модель: `pyannote/speaker-diarization-3.1`

## Синхронизация губ (Wav2Lip)

Если эта функция включена, приложение применяет Wav2Lip GAN для синхронизации движений рта субъекта с дублируемым звуком - кажется, что человек говорит на переведенном языке.

- Модель (~416 МБ) и репозиторий автоматически клонируются при первом использовании в `~/.local/share/wav2lip/`.
- Работает на CUDA (рекомендуется) или ЦП.
- Значительно увеличивает время обработки
- Лучше всего работает на видео с одним, хорошо видимым лицом.

## Требования

- Python 3.10+ (установщик Windows автоматически устанавливает версию 3.11.9)
- Windows 10/11 (x64), Linux или macOS
- **Настоятельно рекомендуется использовать графический процессор NVIDIA** - см. таблицу графических процессоров ниже.
- 20 ГБ свободного места на диске для полной установки (PyTorch CUDA, Whisper big-v3, XTTS, Wav2Lip)

> **ffmpeg и все пакеты Python устанавливаются автоматически** при первом запуске, если они отсутствуют. Ручная настройка не требуется.

**Необязательная системная зависимость** - `rubberband-cli` (Linux: `sudo apt install rubberband-cli`, macOS: `brew install rubberband`). После установки он используется для растяжения времени с сохранением высоты тона в диапазоне качества, контролируемом профилем (по умолчанию 1,15-1,50, до 1,65 для жесткого контента), удаляя остаточный эффект «бурундука» на клонированных голосах XTTS. Без него конвейер работает без изменений (автоматический возврат к ffmpeg `atempo`). Профили качества теперь предпочитают дополнительные короткие попытки перевода чрезмерному ускорению звука.

### Поддержка графического процессора

В конвейере используются пять компонентов с ускорением на графическом процессоре (faster-whisper, Demucs, XTTS, Wav2Lip, pyannote). Охват графических процессоров не одинаков у разных поставщиков:

| GPU | Windows | Linux | Примечания |
|-----|---------|-------|-------|
| **NVIDIA** (RTX 20xx или новее, драйвер CUDA 12.4) | ✅ полный разгон | ✅ полный разгон | **Рекомендуется.** Все 5 компонентов работают на графическом процессоре. |
| **AMD** (Радеон) | ⚠️ неполный (DirectML не поддерживает XTTS и faster-whisper) | ⚠️ частичный (ROCm работает для Demucs/XTTS/pyannote, но faster-whisper поддерживает только CUDA) | Работает, но транскрипция Whisper остается в процессоре и доминирует в общем времени. |
| **Intel Arc** | ⚠️ незрелая поддержка PyTorch XPU | ⚠️ то же самое | Не проверено. |
| **Нет (только ЦП)** | ✅ работает | ✅ работает | Ожидайте, что **в 10-20 раз медленнее**, чем в реальном времени. Просто расшифровка 5-минутного клипа с помощью Whisper big-v3 может занять более 50 минут. |

**Рекомендуемая видеопамять NVIDIA:**

| VRAM | Примеры видеокарт | Опыт |
|------|---------------|-----------|
| 6 ГБ | ГТХ 1660, РТХ 2060 | Можно использовать, нельзя одновременно запускать XTTS + Wav2Lip. |
| 8 ГБ | РТХ 3060 Ти, 4060 | Полный конвейер, без маржи |
| **12 ГБ+** | **RTX 3060 12 ГБ, 4070, 4080** | **Рекомендую - удобно** |
| 24 ГБ | РТХ 3090, 4090 | Запасные мощности для больших партий |

## Установка

### Windows

1. Клонируйте или загрузите этот репозиторий
2. Щелкните правой кнопкой мыши `setup_windows.bat` → **Запуск от имени администратора** → в меню отображается `[1] Install`.
3. Установщик автоматически:
   - Устанавливает Python 3.11, если он отсутствует (для всей системы).
   - Устанавливает Git for Windows, если он отсутствует.
   - Устанавливает все зависимости Python (PyTorch CUDA 12.4, faster-whisper, Demucs, coqui-tts, Wav2Lip deps и т. д.)
   - Скачивает и устанавливает ffmpeg
   - Устанавливает встроенный видеоплеер (python-mpv плюс сборка libmpv в `mpv-runtime`). Этот шаг не является обязательным: если он не удастся, все остальное работает, и на панели проигрывателя объясняется, чего не хватает.
   - Создает **ярлык на общедоступном рабочем столе** (видимый для каждой учетной записи Windows на ПК).

> Установщик является **многопользовательским**: все устанавливается в масштабе всей системы под `%ProgramFiles%\VideoTranslatorAI`, и любой пользователь Windows на компьютере найдет ярлык готовым к работе. Инструменты сборки VS C++ **больше не требуются** - поддерживаемая вилка `coqui-tts` предоставляет предварительно скомпилированные пакеты колеса Python.

### Линукс/МакОС

```bash
# Клонировать репозиторий
git clone https://github.com/HeartB1t/VideoTranslatorAI.git
cd VideoTranslatorAI

# Необязательно: установите протестированный стек NVIDIA CUDA 12.4 PyTorch заранее.
pip install --break-system-packages --index-url https://download.pytorch.org/whl/cu124 -r requirements-gpu-cu124.txt

# Необязательно: предварительно установите все пакеты времени выполнения Python вместо того, чтобы разрешить графическому интерфейсу.
# установить недостающие пакеты при первом запуске
pip install --break-system-packages -r requirements.txt

# Дополнительно: встроенный видеоплеер (libmpv из дистрибутива, python-mpv из PyPI)
sudo apt install libmpv2        # Fedora: mpv-libs, Arch: mpv, openSUSE: libmpv2
pip install --break-system-packages -r requirements-player.txt

# Необязательно: установите проект как редактируемый пакет Python.
pip install --break-system-packages --no-deps -e .

# Запуск из исходников
python video_translator_gui.py

# Или после установки редактирования/пакета
videotranslatorai
videotranslatorai --preflight
```

> При первом запуске графический интерфейс обнаруживает все недостающие пакеты (faster-whisper, Demucs, Edge-TTS и т. д.) и автоматически устанавливает их, передавая выходные данные в окно журнала. ffmpeg также устанавливается автоматически через `apt-get`/`dnf`/`pacman` (Linux) или загружается с GitHub (Windows).

> В заголовке отображается значок **Игрок**. Если libmpv или python-mpv отсутствуют, на левой панели указывается, чего не хватает, и предлагается **Установить проигрыватель**: в Linux он использует менеджер пакетов через pkexec (затем `sudo -n`) и показывает команду вручную, когда ни одна из них не работает; в Windows он запрашивает перед загрузкой libmpv для текущего пользователя (около 32 МБ).

## Удалить

### Windows

Запустите `setup_windows.bat` (щелкните правой кнопкой мыши → **Запуск от имени администратора**) и выберите `[3] Uninstall` в меню. Предлагаются три подрежима удаления:

| Режим | Требуется администратор | Область применения |
|------|----------------|-------|
| **[1] Полное удаление - один клик** | ✅ | Удаляет папку приложения, ярлык общедоступного рабочего стола, ffmpeg из PATH компьютера, кэш модели HF каждого пользователя (Whisper/XTTS) и конфигурацию (`HF token`), а также все пакеты Python AI, установленные установщиком. В конце он также спрашивает (согласно), следует ли удалить **Python 3.11** и **Git for Windows** в автоматическом режиме с помощью строк тихого удаления в их реестре. |
| **[2] Только текущий пользователь** | ❌ | Удаляется только конфигурация VTAI работающего пользователя, кэш HF/XTTS и устаревшая установка для каждого пользователя. **Оставляет общесистемную установку без изменений**, поэтому другие учетные записи Windows на ПК могут продолжать использовать приложение. |
| **[3] Пользовательский - детальный** | ✅ для системных элементов, ❌ для пользовательских элементов | Запрос Y/N для каждой категории: папка приложения, ярлык, PATH компьютера, устаревшие установки для каждого пользователя, конфигурации/кэши для каждого пользователя, затем сгруппированные пакеты Python (TTS, стек PyTorch, Whisper+ctranslate2, Demucs, Wav2Lip deps, pyannote, утилиты конвейера) и, наконец, необязательные Python 3.11 и Git. |

**Никогда не удаляется автоматически:** Инструменты сборки Visual Studio C++ (если они присутствуют в более ранних версиях). Используйте *Приложения и функции* в настройках Windows, чтобы при необходимости удалить их вручную.

## Использование

### Диагностика

```bash
python video_translator_gui.py --preflight
python video_translator_gui.py --preflight --preflight-lipsync
python video_translator_gui.py --preflight --preflight-player
python -m videotranslator --preflight
```

Запускает диагностику локальной среды, не запуская перевод и ничего не устанавливая. `--preflight-lipsync` обрабатывает пакеты лиц Wav2Lip по мере необходимости, что полезно перед включением **Lip Sync**. Графический интерфейс предоставляет ту же базовую проверку, что и кнопку **Диагностика** на панели журнала. `--preflight-player` обрабатывает встроенный видеоплеер (python-mpv и загружаемую библиотеку libmpv) по мере необходимости. `python -m videotranslator.libmpv_runtime check` проверяет только libmpv (выход 0 готов, 2 недоступен).

### GUI

```bash
python video_translator_gui.py
```

**Макет:** настройки пакетного перевода находятся в столбце справа в виде набора панелей настроек: **Ввод**, **Перевод**, **Профиль рабочего процесса**, **Начало**, а также сворачиваемые расширенные разделы (модель, механизм перевода, звук, клонирование голоса, синхронизация губ, ведение дневника, параметры, горячие слова). Большая область слева - это **интегрированный видеоплеер** (транспорт, список воспроизведения, оригинал A/B или дублированный звук, субтитры, снимок, полноэкранный режим) с панелью **перевода в реальном времени** под ним. Перетащите карточку за заголовок или за маркер **≡**, чтобы переместить ее вверх или вниз по столбцу; порядок сохраняется (`ui_panel_order`) и восстанавливается при следующем запуске. Панель журнала внизу можно скрыть с помощью **Скрыть журнал**. При запуске окно открывается по центру текущего монитора (того, что под указателем) и развернуто до максимума, поэтому оно хорошо работает при настройке нескольких мониторов.

**Элементы управления видеопроигрывателем:** значки имеют одинаковые функциональные цвета в каждой теме, независимо от выбранного акцентного цвета:

| Контроль | Цвет |
|---------|--------|
| Воспроизвести видео | Зеленый |
| Пауза (заменяет «Воспроизведение» во время игры) | Янтарь |
| Остановить воспроизведение | Кораллово-красный |
| Назад/назад 10 с/вперед 10 с/следующий | Синий |
| Снимок | Фиолетовый |
| Открыть папку | Золото |

При наведении курсора мыши добавляется тонкий тонированный фон. Недоступные элементы управления нейтральны; Навигация по списку воспроизведения остается доступной после остановки. Подсказки и индикаторы фокуса клавиатуры остаются доступными, поэтому цвет - не единственный способ обозначить действия.

**Из локальных файлов:**
1. Нажмите **Добавить**, чтобы выбрать один или несколько видеофайлов.
2. Выберите исходный и целевой язык
3. Откройте раздел **Модель** и выберите модель Whisper (`small` - хороший баланс скорости и точности).
4. Выберите голос и при необходимости отрегулируйте скорость TTS.
5. *(Необязательно)* В разделе **Система перевода** выберите **Google** (по умолчанию), **MarianMT** (локальный/офлайн), **DeepL Free** или **Ollama LLM** (локальный, рекомендуется для голосового дубляжа).
6. *(Необязательно)* Включите **Клонирование голоса** (XTTS v2) и/или **идентификацию говорящих (диаризирование)**
7. *(Необязательно)* Включить **синхронизацию губ** (Wav2Lip)
8. Нажмите **Начать перевод**.

**С YouTube (или любого поддерживаемого сайта):**
1. Вставьте один или несколько URL-адресов в поле **URL** (по одному в строке).
2. Настройте язык, модель и голос как обычно
3. Нажмите **⬇ Скачать и перевести**

> yt-dlp поддерживает YouTube, Vimeo, Twitter/X, TikTok и [более 1000 других сайтов](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md).

> ⚠️ **Примечание о добросовестном использовании**. Загрузка видео через yt-dlp считается автоматическим доступом на таких платформах, как YouTube, и может нарушать их Условия использования. Интенсивное или повторное использование одного и того же IP-адреса может привести к временной блокировке (ошибки HTTP 429/требования входа в систему). Используйте VPN или поменяйте свой IP-адрес, если у вас возникли сбои при загрузке. Этот инструмент предназначен только для личного некоммерческого использования. Распространение переведенного контента может нарушать авторские права - всегда соблюдайте права оригинального создателя.

### Перевод в реальном времени (субтитры и экспериментальное озвучивание)

Посмотрите локальный файл или разрешенную ссылку на видео по запросу с переведенными субтитрами и дополнительным устным переводом. Используйте панель под плеером:

**По ссылке:**

1. Вставьте ссылку в поле **URL**.
2. Установите исходный и целевой язык, выберите голос и отрегулируйте ползунок **Задержка**.
3. Выберите **Озвучка** и/или **Субтитры**.
4. Чтобы слышать только переведенный голос, перед началом выберите **Отключить исходный звук** (на итальянском языке: **Silenzia originale**, рядом с флажком субтитров).
5. Нажмите **Перевести в реальном времени** - ссылка будет разрешена, и начнется перевод.

**Из загруженного файла** загрузите видео в плеер (Ввод -> Добавить, затем выберите его), оставьте поле URL пустым, выберите те же настройки трансляции и нажмите **Перевести в реальном времени**. URL-адрес имеет приоритет, если поле не пусто.

- **Ядро:** MarianMT (офлайн, по умолчанию), Google, DeepL или Ollama. Распознавание речи (Whisper) выполняется локально. Автономные модели требуют первоначальной загрузки.
- **Голосовое дубляж:** экспериментальное воспроизведение речи Edge-TTS через второй экземпляр mpv. Для этого требуется доступ в Интернет, и он не связан с пакетным голосовым клонированием.
- **Отключение звука оригинала:** доступно как перед запуском, так и во время перевода. Он заглушает весь оригинальный саундтрек, включая музыку и эффекты, но оставляет слышимым переведенный голос. Он не изолирует человека, говорящего в исходном аудио. Выключите его, чтобы восстановить саундтрек; он сбрасывается, когда заканчивается сеанс реального времени. Кнопка динамика плеера служит для общего отключения звука, а не для независимого управления.
- **Пауза и поиск:** элементы управления видеопроигрывателем подключены к сеансу прямой трансляции; сквозная синхронизация звука по-прежнему требует приемочных испытаний для конкретной платформы.
- **Текущие ограничения:** обработка наложения/затухания клипов, калибровка синхронизации звука и поддержка Windows остаются открытыми. Растущие прямые трансляции пока не поддерживаются; метка режима реального времени не подразумевает поддержку приема трансляции по мере ее роста. См. [статус реализации и оставшаяся работа](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).

Для сохраненного дублированного видео используйте **Загрузить и перевести** / **Начать перевод** вместо предварительного просмотра в реальном времени.

### Блоки механизма перевода и VPN

Могут возникнуть два разных блока с разными исправлениями:

| Блокировать | Симптом | Исправить |
|-------|---------|-----|
| **Скачать** (yt-dlp) | «Войдите, чтобы подтвердить, что вы не бот», HTTP 429 | **VPN** / поменяйте IP-адрес или войдите на YouTube в браузере (файлы cookie считываются автоматически) |
| **Перевод** (бесплатная конечная точка Google) | «Google Translate не удалось перевести... частота запросов ограничена/заблокирована» | Используйте **MarianMT** (офлайн) или **Ollama** (локально) - без ограничения частоты запросов. VPN также помогает. Пакетный поток теперь **автоматически возвращается к MarianMT**, когда Google блокируется. |

### Темы и внешний вид

Нажмите на значок шестеренки в заголовке, чтобы открыть **Настройки**:

- **Тема**: Автоматически (соответствует темному/светлому режиму ОС), Graphite (по умолчанию), Slate, Light, Neon.
- **Акцентный цвет**: по умолчанию для каждой темы: синий, бирюзовый, фиолетовый, зеленый, янтарный, розовый.
- **Размер текста**: маленький, нормальный, большой, очень большой.
- **Язык интерфейса**: 26 языков.

Изменения применяются сразу, без перезагрузки, и сохраняются в файле конфигурации (`ui_theme`, `ui_accent`, `ui_scale`, `ui_lang`). **Восстановить настройки по умолчанию** возвращает тему Graphite, акцент по умолчанию, нормальный размер текста и порядок панелей настроек по умолчанию.

### интеграционные тесты с реальными моделями

Набор тестов по умолчанию позволяет избежать загрузки реальных моделей и длительной работы графического процессора. Чтобы запустить добровольную эмпирическую проверку установленного локального стека:

```bash
VTAI_RUN_HEAVY_SMOKE=1 python -m unittest discover -s tests -p "test_heavy_smoke.py" -v
```

Эти проверки проверяют реальный импорт Wav2Lip, доступность Torch CUDA, доступность демона Ollama и faster-Whisper для синтетической речи. Они намеренно терпят неудачу или пропускают работу, когда состояние локального драйвера/демона/модели не готово.

**Примеры:**

```bash
# Переведите итальянское видео на английский с помощью местного MarianMT
# (загружается модель размером ~298 МБ при первом использовании, затем полностью в автономном режиме)
python video_translator_gui.py video.mp4 --lang-source it --lang-target en --translation-engine marian

# Перевод с клонированием голоса + идентификация говорящих (диаризация)
python video_translator_gui.py interview.mp4 --lang-target en --diarize --hf-token hf_xxx

# Переводите с синхронизацией губ
python video_translator_gui.py video.mp4 --lang-target en --lipsync

# Только субтитры (без озвучки)
python video_translator_gui.py video.mp4 --lang-target fr --subs-only
```

## Автономный модуль CLI

Модульный пакет предоставляет четыре пользовательских инструмента, которые можно вызывать напрямую, не запуская весь конвейер:

```bash
# Предполетное видео для присутствия лица (Wav2Lip будет пропущено, если его нет).
python3 -m videotranslator.face_detector path/to/video.mp4
# выход 0 = лицо присутствует, выход 1 = лица нет

# Проанализируйте файл *_metrics.csv, созданный build_dubbed_track.
# Отчеты P50/P75/P90/P95 pre_stretch_ratio, пробой полосы слышимости,
# использование механизма растяжения и топ-N худших выбросов с их целевым текстом.
python3 -m videotranslator.metrics_csv path/to/video_metrics.csv

# Очистка текста для TTS (перезапись двоеточий, точек с запятой, многоточий, тире).
echo "alle 10:30 ho detto: andiamo!" | python3 -m videotranslator.tts_text_sanitizer

# Оцените сложность озвучивания по файлу сегментов .srt или .json ПЕРЕД запуском TTS.
python3 -m videotranslator.difficulty_detector path/to/video_it.srt --target-lang it --expansion 1.25
```

Каждый инструмент имеет `-h`/`--help` для полных опций. Они автономны и повторно используют те же модули, на которых основан конвейер голосового дублирования, поэтому их выходные данные остаются согласованными со средой выполнения.

Windows: сначала опробуется сборка LGPL от zhongfly (https://github.com/zhongfly/mpv-winbuild); Закрепленная сборка GPL от Shinchiro (https://sourceforge.net/projects/mpv-player-windows/files/libmpv/) является запасным вариантом. `mpv-runtime\BUILD.txt` записывает исходный код, версию лицензии и фиксацию mpv, а текст лицензии находится рядом с DLL. Linux: дистрибутив (`libmpv2`, `libmpv1`, `mpv-libs` или `mpv`).
- **FFmpeg** внутри libmpv (LGPL или GPL, после сборки libmpv).
- **python-mpv** (`mpv` на PyPI), GPLv2+ или LGPLv2.1+.
- **7-Zip `7zr.exe`** 26.03 (LGPL), используется установщиком Windows для извлечения libmpv и впоследствии удаляется.
- **Загрузчик Vulkan** (Khronos, MIT и Apache-2.0), загружается в Windows только при отсутствии `vulkan-1.dll`.
- **edge-tts** (LGPLv3), используемый конвейером голосового дублирования.
- **Модели MarianMT** (Хельсинки-NLP), загруженные с Hugging Face Hub при первом использовании по собственным лицензиям (Apache-2.0 для моделей `opus-mt`, CC-BY-4.0 для `opus-mt-tc-big`).
