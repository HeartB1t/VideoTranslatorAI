Εργαλείο μεταγλώττισης φωνής βίντεο με τεχνητή νοημοσύνη, το οποίο μεταγράφει αυτόματα, μεταφράζει και εκ νέου μεταγλωττίζει βίντεο σε 26 γλώσσες, με επιλογές τοπικής επεξεργασίας και χωρίς κλειδιά API που απαιτούνται από προεπιλογή. Η αναγνώριση ομιλίας Whisper εκτελείται τοπικά. Τα Edge-TTS, Google Translate και DeepL απαιτούν σύνδεση στο διαδίκτυο. Οι προαιρετικές λειτουργίες (DeepL, αναγνώριση ατόμων που μιλούν (diarization)) ενδέχεται να απαιτούν κλειδί API ή διακριτικό πρόσβασης.

> **v2.0** - αρθρωτό πακέτο, τοπική μετάφραση Ollama, ενορχήστρωση προφίλ ποιότητας, μεταδεδομένα Python με δυνατότητα εγκατάστασης και δοκιμές ολοκλήρωσης συμμετοχής με πραγματικά μοντέλα. Δείτε το [GitHub Releases](https://github.com/HeartB1t/VideoTranslatorAI/releases) και το ιστορικό δέσμευσης για την πλήρη λίστα αλλαγών.

## Πώς λειτουργεί

1. **Μεταγραφή** - [faster-Whisper](https://github.com/SYSTRAN/faster-whisper) μεταγράφει τον ήχο (επιτάχυνση GPU)
2. **Διαχωρισμός φωνής/μουσικής** - Το [Demucs](https://github.com/facebookresearch/demucs) απομονώνει τα φωνητικά από τη μουσική υπόκρουση
3. **Μετάφραση** - MarianMT (τοπική, εκτός σύνδεσης), Google Translate, DeepL Free ή **Ollama LLM** (Qwen3, συνοπτικές μεταφράσεις με γνώση slot)
4. **αναγνώριση ατόμων που μιλούν (diarization)** *(προαιρετικό)* - [pyannote-audio](https://github.com/pyannote/pyannote-audio) προσδιορίζει ποιος μιλάει σε κάθε τμήμα
5. **Μετεγγραφή φωνής** - [Edge-TTS](https://github.com/rany2/edge-tts) (400+ φωνές) ή [Coqui XTTS v2](https://github.com/coqui-ai/TTS) (κλωνοποίηση φωνής, για κάθε ομιλητή στη συνομιλία)
6. **Μίξη** - μεταγλωττισμένη φωνή σε συνδυασμό με πρωτότυπη μουσική υπόκρουση
7. **Normalization** - τελικός ήχος κανονικοποιημένος σε -23 LUFS (πρότυπο εκπομπής EBU R128)
8. **Lip Sync** *(προαιρετικό)* - [Wav2Lip](https://github.com/Rudrabha/Wav2Lip) συγχρονίζει τις κινήσεις του στόματος με τον μεταγλωττισμένο ήχο

## Χαρακτηριστικά

- 🖥️ Θεματικό GUI (Tkinter) - δεν απαιτείται γραμμή εντολών. Θέματα Graphite, Slate, Light και Neon, χρώματα έμφασης, μέγεθος κειμένου και πίνακες ρυθμίσεων που μπορείτε να αναδιατάξετε σύροντας
- 🌍 **26 γλώσσες-στόχους** με πολλές φωνές ανά γλώσσα
- 🌐 **UI σε 26 γλώσσες** - η ίδια η διεπαφή προσαρμόζεται στη γλώσσα σας
- 🎬 **Υποστήριξη YouTube & URL** - επικολλήστε οποιονδήποτε σύνδεσμο YouTube και μεταφράστε απευθείας (με την υποστήριξη του yt-dlp)
- ▶️ **Ενσωματωμένο πρόγραμμα αναπαραγωγής βίντεο** (libmpv/mpv) - έγχρωμα κωδικοποιημένα στοιχεία ελέγχου μεταφοράς, λίστα αναπαραγωγής, πρωτότυπο A/B έναντι μεταγλωττισμένου ήχου, εναλλαγή υπότιτλων, στιγμιότυπο, πλήρης οθόνη, ανοιχτός φάκελος
- ⏱️ **Μετάφραση σε πραγματικό χρόνο** - παρακολουθήστε ένα τοπικό αρχείο ή έναν επιλυμένο σύνδεσμο βίντεο κατ' απαίτηση με μεταφρασμένους υπότιτλους και ένα ρυθμιστικό καθυστέρησης τύπου YouTube. μηχανές MarianMT / Google / DeepL / Ollama. Η πειραματική μεταγλώττιση φωνής χρησιμοποιεί Edge-TTS και ένα δεύτερο παράδειγμα mpv. Ο χειρισμός της επικάλυψης φωνής και η πραγματική αποδοχή ήχου/Windows παραμένουν σε εξέλιξη. Οι αυξανόμενες ζωντανές μεταδόσεις δεν υποστηρίζονται ακόμη. Δείτε την [κατάσταση ζωντανής υλοποίησης](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).
- 🎵 Διαχωρισμός φωνής/μουσικής μέσω Demucs (διατηρεί τη μουσική υπόκρουση)
- 🔇 **Σίγαση του αρχικού ήχου**, διαθέσιμη πριν και κατά τη ζωντανή μετάφραση, θέτει σε σίγαση το soundtrack του βίντεο ενώ διατηρεί τη μεταφρασμένη φωνή ακουστή. Απενεργοποιήστε το για να επαναφέρετε τον αρχικό ήχο. επαναφέρεται όταν τελειώσει η ζωντανή περίοδος λειτουργίας.
- 🧠 **MarianMT** - πλήρως τοπική, εκτός σύνδεσης νευρική μετάφραση (Ελσίνκι-NLP, χωρίς όρια ποσοστού αιτήματος, χωρίς κλειδί API)
- 🤖 **Μετάφραση Ollama LLM** *(νέο σε έκδοση 2.0)* - τοπικό LLM (Qwen3, Llama, Mistral) που παράγει συνοπτικές μεταφράσεις με γνώσεις υποδοχής για φυσική μεταγλώττιση φωνής, αυτόματη ανίχνευση/εγκατάσταση/εκκίνηση/τραβήξη μοντέλου κατά την πρώτη χρήση
- 🎙️ **Κλωνοποίηση φωνής** - Το Coqui XTTS v2 κλωνοποιεί το άτομο που μιλάει με τη φωνή του αρχικού ήχου στη γλώσσα-στόχο (μοντέλο ~ 1,8 GB), με προσαρμοστική ταχύτητα ανά τμήμα και επανάληψη πολλαπλών σπόρων σε παραισθήσεις
- 👥 **ταυτοποίηση ατόμων που μιλούν (diarization)** - το pyannote-audio 3.1 προσδιορίζει πολλά άτομα που μιλούν. Το XTTS κλωνοποιεί κάθε φωνή ξεχωριστά
- 💋 **Lip Sync** - Το Wav2Lip GAN συγχρονίζει τις κινήσεις του στόματος με τον μεταγλωττισμένο ήχο (~416 MB μοντέλο)
- 🔊 **Ομαλοποίηση ήχου** - αυτόματη κανονικοποίηση έντασης ήχου -23 LUFS (EBU R128)
- ✏️ Επεξεργαστής υποτίτλων - ελέγξτε και διορθώστε τους υπότιτλους πριν από τη φωνητική μεταγλώττιση
- 📦 Μαζική επεξεργασία - μεταφράστε πολλά βίντεο ή διευθύνσεις URL ταυτόχρονα
- ⚡ Επιτάχυνση GPU μέσω CUDA (επιστρέφει αυτόματα στην CPU)
- 📄 Προαιρετική εξαγωγή υποτίτλων `.srt`
- 🔁 **DeepL Free** μηχανή μετάφρασης (προαιρετικό - 500.000 χαρακτήρες/μήνα, απαιτεί δωρεάν κλειδί API)
- 🔧 **Αυτόματη εγκατάσταση** - τα πακέτα Python που λείπουν και το ffmpeg εγκαθίστανται αυτόματα κατά την πρώτη εκκίνηση

| **MarianMT** | Κανένα - λήψεις ~298 MB ανά ζεύγος γλωσσών κατά την πρώτη χρήση | Κανένα - πλήρως εκτός σύνδεσης μετά τη λήψη | ★★★★ |
| **DeepL Free** | Δωρεάν κλειδί API στο [deepl.com](https://www.deepl.com/pro-api) | 500.000 χαρακτήρες/μήνα | ★★★★★ |
| **Ollama LLM** *(συνιστάται για μεταγλώττιση φωνής - νέο σε έκδοση 2.0)* | Αυτόματη εγκατάσταση κατά την πρώτη χρήση (~1 GB Ollama + μοντέλο 5 GB) | Κανένα - πλήρως τοπικό | ★★★★★ |

> Το **MarianMT** χρησιμοποιεί μοντέλα [Helsinki-NLP/opus-mt](https://huggingface.co/Helsinki-NLP), αποθηκευμένα στην προσωρινή μνήμη τοπικά μετά την πρώτη λήψη. Απαιτεί ρητή γλώσσα πηγής (η αυτόματη ανίχνευση δεν υποστηρίζεται - επιλέξτε μη αυτόματα τη γλώσσα πηγής). Τα απαιτούμενα πακέτα Python (`sacremoses`, `sentencepiece`) εγκαθίστανται αυτόματα στην πρώτη επιλογή εάν λείπουν.

> Το **Ollama LLM** *(νέο σε έκδοση 2.0)* είναι η προτεινόμενη μηχανή για μεταγλώττιση φωνής, επειδή παράγει μεταφράσεις με επίγνωση της χρονικής θυρίδας στόχου. Όπου το MarianMT μεταφράζει κυριολεκτικά και παράγει Ιταλικά / Ισπανικά / Γαλλικά ~25% περισσότερο από τα Αγγλικά (επιβάλλοντας συμπίεση ήχου στο TTS), το LLM ζητείται να διατηρεί κάθε τμήμα συνοπτικό και φυσικό για προφορική παράδοση, επιτυγχάνοντας μια τυπική αναλογία χαρακτήρων 0,85-0,95 έναντι της πηγής. Το προεπιλεγμένο μοντέλο είναι `qwen3:8b` (5,2 GB στο δίσκο, ~6 GB VRAM). Το `qwen3:4b` (~3 GB) είναι η ελαφριά επιλογή, το `qwen3:14b` η υψηλότερης ποιότητας. Η διοχέτευση ανιχνεύει αυτόματα το δυαδικό σύστημα Ollama, το εγκαθιστά αυτόματα μέσω του επίσημου προγράμματος εγκατάστασης κατά την πρώτη χρήση (με αναδυόμενο παράθυρο συγκατάθεσης), εκκινεί τον δαίμονα και τραβά το επιλεγμένο μοντέλο - δεν απαιτείται μη αυτόματη ρύθμιση. Μεταβαίνει αυτόματα σε Google Translate εάν λείπει κάτι.

## Κλωνοποίηση φωνής (XTTS v2)

Όταν είναι ενεργοποιημένη, η εφαρμογή εξάγει τη φωνή του ομιλητή από το αρχικό βίντεο και τη χρησιμοποιεί ως αναφορά για την κλωνοποίηση της φωνής στη γλώσσα-στόχο.

- Υποστηριζόμενες γλώσσες: AR, ZH, CS, DE, EN, ES, FR, HI, HU, IT, JA, KO, NL, PL, PT, RU, TR (17/26)
- Για τις υπόλοιπες 9 γλώσσες, το Edge-TTS χρησιμοποιείται αυτόματα ως εναλλακτική
- Μοντέλο (~1,8 GB) έγινε αυτόματη λήψη κατά την πρώτη χρήση στο `~/.local/share/tts/`
- **Αναφορά με φίλτρο VAD** (v1.4): 10-15 s συνεχούς ομιλίας επιλεγμένη από τον αρχικό ήχο μέσω [silero-vad](https://github.com/snakers4/silero-vad) για καλύτερη ποιότητα κλωνοποίησης φωνής
- **Ταχύτητα γενιάς** με δυνατότητα διαμόρφωσης (`xtts_speed`, προεπιλογή `1.25`): οι υψηλότερες τιμές μειώνουν τα τεχνουργήματα συμπίεσης ήχου μετά την επεξεργασία όταν το μεταφρασμένο κείμενο είναι μεγαλύτερο από την υποδοχή πηγής. Συντονιστείτε μέσω `~/.config/videotranslatorai/config.json` ή CLI `--xtts-speed`
- Λειτουργεί σε CUDA ή CPU

## αναγνώριση ατόμων που μιλούν (diarization) (pyannote-audio)

Όταν είναι ενεργοποιημένη, η εφαρμογή προσδιορίζει ποιος μιλάει σε κάθε τμήμα. Σε συνδυασμό με την Κλωνοποίηση φωνής, η φωνή κάθε ομιλητή κλωνοποιείται ξεχωριστά - ιδανική για συνεντεύξεις, podcast και βίντεο πολλών ατόμων.

- Απαιτείται δωρεάν [HuggingFace token](https://huggingface.co/settings/tokens) (εφάπαξ εγγραφή)
- **Το διακριτικό αποθηκεύεται με ασφάλεια** (v1.4) μέσω του μπρελόκ του λειτουργικού συστήματος: Windows Credential Manager, macOS Keychain, Linux Secret Service. Αυτόματη μετεγκατάσταση από προηγούμενο χώρο αποθήκευσης JSON απλού κειμένου
- Μετά την πρώτη λήψη, λειτουργεί πλήρως εκτός σύνδεσης
- Μοντέλο: `pyannote/speaker-diarization-3.1`

## Lip Sync (Wav2Lip)

Όταν είναι ενεργοποιημένη, η εφαρμογή εφαρμόζει το Wav2Lip GAN για να συγχρονίσει τις κινήσεις του στόματος του θέματος με τον μεταγλωττισμένο ήχο - το άτομο φαίνεται να μιλά τη μεταφρασμένη γλώσσα.

- Μοντέλο (~416 MB) και το repo κλωνοποιήθηκε αυτόματα κατά την πρώτη χρήση στο `~/.local/share/wav2lip/`
- Λειτουργεί σε CUDA (συνιστάται) ή CPU
- Αυξάνει σημαντικά τον χρόνο επεξεργασίας
- Λειτουργεί καλύτερα σε βίντεο με ένα μόνο, καθαρά ορατό πρόσωπο

## Απαιτήσεις

- Python 3.10+ (το πρόγραμμα εγκατάστασης των Windows προβλέπει αυτόματα το 3.11.9)
- Windows 10 / 11 (x64), Linux ή macOS
- **NVIDIA GPU συνιστάται ανεπιφύλακτα** - δείτε τον παρακάτω πίνακα GPU
- 20 GB ελεύθερος χώρος στο δίσκο για πλήρη εγκατάσταση (PyTorch CUDA, Whisper large-v3, XTTS, Wav2Lip)

> Το **ffmpeg και όλα τα πακέτα Python εγκαθίστανται αυτόματα** κατά την πρώτη εκκίνηση εάν λείπουν. Δεν απαιτείται χειροκίνητη ρύθμιση.

**Προαιρετική εξάρτηση συστήματος** - `rubberband-cli` (Linux: `sudo apt install rubberband-cli`, macOS: `brew install rubberband`). Όταν είναι εγκατεστημένο, χρησιμοποιείται για διατήρηση της έντασης χρόνου στην ελεγχόμενη από προφίλ ζώνη ποιότητας (προεπιλογή 1,15-1,50, έως 1,65 για σκληρό περιεχόμενο), αφαιρώντας το υπολειπόμενο αποτέλεσμα "chipmunk" σε κλωνοποιημένες φωνές XTTS. Ο αγωγός λειτουργεί αμετάβλητος χωρίς αυτό (αυτόματη επαναφορά σε ffmpeg `atempo`). Τα ποιοτικά προφίλ προτιμούν πλέον τις πρόσθετες επαναλήψεις σύντομης μετάφρασης από την ακραία επιτάχυνση ήχου.

### Υποστήριξη GPU

Ο αγωγός χρησιμοποιεί πέντε στοιχεία με επιτάχυνση GPU (faster-whisper, Demucs, XTTS, Wav2Lip, pyannote). Η κάλυψη GPU δεν είναι ομοιόμορφη μεταξύ των προμηθευτών:

| GPU | Windows | Linux | Σημειώσεις |
|-----|---------|-------|-------|
| **NVIDIA** (RTX 20xx ή νεότερο, πρόγραμμα οδήγησης CUDA 12.4) | ✅ πλήρης επιτάχυνση | ✅ πλήρης επιτάχυνση | **Συνιστάται.** Και τα 5 στοιχεία τρέχουν σε GPU. |
| **AMD** (Radeon) | ⚠️ ελλιπής (το DirectML δεν υποστηρίζει XTTS και faster-whisper) | ⚠️ μερικό (το ROCm λειτουργεί για Demucs/XTTS/pyannote αλλά το faster-whisper υποστηρίζει μόνο CUDA) | Λειτουργεί αλλά η μεταγραφή Whisper παραμένει στην CPU και κυριαρχεί στον συνολικό χρόνο. |
| **Intel Arc** | ⚠️ Ανώριμη υποστήριξη PyTorch XPU | ⚠️ το ίδιο | Δεν έχει δοκιμαστεί. |
| **Κανένα (μόνο CPU)** | ✅ λειτουργεί | ✅ λειτουργεί | Αναμένετε **10-20× πιο αργό** από τον πραγματικό χρόνο. Ένα κλιπ διάρκειας 5 λεπτών μπορεί να χρειαστούν 50+ λεπτά μόνο για να μεταγραφεί με το Whisper large-v3. |

**Προτεινόμενη NVIDIA VRAM:**

| VRAM | Συνήθεις κάρτες γραφικών | Εμπειρία |
|------|---------------|-----------|
| 6 GB | GTX 1660, RTX 2060 | Μπορεί να χρησιμοποιηθεί, δεν είναι δυνατή η ταυτόχρονη εκτέλεση XTTS + Wav2Lip |
| 8 GB | RTX 3060 Ti, 4060 | Πλήρης αγωγός, χωρίς περιθώριο |
| **12 GB+** | **RTX 3060 12 GB, 4070, 4080** | **Συνιστάται - άνετο** |
| 24 GB | RTX 3090, 4090 | Εφεδρική χωρητικότητα για μεγάλες παρτίδες |

## Εγκατάσταση

### Windows

1. Κλωνοποιήστε ή κατεβάστε αυτό το αποθετήριο
2. Κάντε δεξί κλικ στο `setup_windows.bat` → **Εκτέλεση ως διαχειριστής** → το μενού εμφανίζει `[1] Install`
3. Το πρόγραμμα εγκατάστασης αυτόματα:
   - Εγκαθιστά την Python 3.11 εάν δεν υπάρχει (σε όλο το σύστημα)
   - Εγκαθιστά το Git for Windows εάν δεν υπάρχει
   - Εγκαθιστά όλες τις εξαρτήσεις Python (PyTorch CUDA 12.4, faster-whisper, Demucs, coqui-tts, Wav2Lip deps, κ.λπ.)
   - Λήψη και εγκατάσταση του ffmpeg
   - Εγκαθιστά το ενσωματωμένο πρόγραμμα αναπαραγωγής βίντεο (python-mpv συν μια έκδοση libmpv στο `mpv-runtime`). Το βήμα είναι προαιρετικό: εάν αποτύχει, όλα τα άλλα λειτουργούν και το παράθυρο του προγράμματος αναπαραγωγής εξηγεί τι λείπει
   - Δημιουργεί μια **συντόμευση δημόσιας επιφάνειας εργασίας** (ορατή σε κάθε λογαριασμό Windows στον υπολογιστή)

> Το πρόγραμμα εγκατάστασης είναι **πολλαπλών χρηστών**: όλα εγκαθίστανται σε όλο το σύστημα στο `%ProgramFiles%\VideoTranslatorAI` και οποιοσδήποτε χρήστης των Windows στο μηχάνημα βρίσκει τη συντόμευση έτοιμη για χρήση. ### GUI

```bash
python video_translator_gui.py
```

**Διάταξη:** ομαδικές ρυθμίσεις μετάφρασης βρίσκονται στη στήλη στα δεξιά, ως στοίβα πλαισίων ρυθμίσεων: **Είσοδος**, **Μετάφραση**, **Προφίλ ροής εργασίας**, **Έναρξη** και οι πτυσσόμενες σύνθετες ενότητες (μοντέλο, μηχανή μετάφρασης, ήχος, κλωνοποίηση φωνής, συγχρονισμός χειλιών, diarization, επιλογές, λέξεις-κλειδιά). Η μεγάλη περιοχή στα αριστερά είναι το **ενσωματωμένο πρόγραμμα αναπαραγωγής βίντεο** (μεταφορά, playlist, πρωτότυπο A/B έναντι μεταγλωττισμένου ήχου, υπότιτλοι, στιγμιότυπο, πλήρης οθόνη), με τη γραμμή **μετάφρασης σε πραγματικό χρόνο** από κάτω. Σύρετε μια κάρτα από τον τίτλο της ή από τη λαβή **≡** για να την μετακινήσετε πάνω ή κάτω στη στήλη. η παραγγελία αποθηκεύεται (`ui_panel_order`) και αποκαθίσταται στην επόμενη εκκίνηση. Ο πίνακας καταγραφής στο κάτω μέρος μπορεί να κρυφτεί με **Απόκρυψη αρχείου καταγραφής**. Κατά την εκκίνηση, το παράθυρο ανοίγει κεντραρισμένο στην τρέχουσα οθόνη (αυτή που βρίσκεται κάτω από τον δείκτη) και μεγιστοποιείται, ώστε να συμπεριφέρεται καλά σε μια εγκατάσταση πολλαπλών οθονών.

**Στοιχεία ελέγχου προγράμματος αναπαραγωγής βίντεο:** Τα εικονίδια χρησιμοποιούν σταθερά λειτουργικά χρώματα σε κάθε θέμα, ανεξάρτητα από το επιλεγμένο χρώμα έμφασης:

| Έλεγχος | Χρώμα |
|---------|--------|
| Αναπαραγωγή βίντεο | Πράσινο |
| Παύση (αντικαθιστά την αναπαραγωγή κατά την αναπαραγωγή) | Κεχριμπάρι |
| Διακοπή αναπαραγωγής | Κοραλί κόκκινο |
| Προηγούμενο / πίσω 10 δ. / εμπρός 10 δ. / επόμενο | Μπλε |
| Στιγμιότυπο | Βιολετί |
| Άνοιγμα φακέλου | Χρυσός |

Η αιώρηση προσθέτει ένα διακριτικό χρωματισμένο φόντο. Τα μη διαθέσιμα στοιχεία ελέγχου είναι ουδέτερα. Η πλοήγηση στη λίστα αναπαραγωγής παραμένει χρησιμοποιήσιμη μετά τη Διακοπή. Επεξηγήσεις εργαλείων και ενδείξεις εστίασης πληκτρολογίου παραμένουν διαθέσιμες, επομένως το χρώμα δεν είναι ο μόνος τρόπος αναγνώρισης ενεργειών.

**Από τοπικά αρχεία:**
1. Κάντε κλικ στο **Προσθήκη** για να επιλέξετε ένα ή περισσότερα αρχεία βίντεο
2. Επιλέξτε γλώσσα πηγής και προορισμού
3. Ανοίξτε την ενότητα **Μοντέλο** και επιλέξτε ένα μοντέλο Whisper (το `small` είναι μια καλή ισορροπία ταχύτητας/ακρίβειας)
4. Επιλέξτε μια φωνή και προσαρμόστε την ταχύτητα TTS εάν χρειάζεται
5. *(Προαιρετικό)* Στη **Μηχανή μετάφρασης** επιλέξτε **Google** (προεπιλογή), **MarianMT** (τοπικό/εκτός σύνδεσης), **DeepL Free** ή **Ollama LLM** (τοπικό, συνιστάται για μεταγλώττιση φωνής)
6. *(Προαιρετικό)* Ενεργοποίηση **Voice Cloning** (XTTS v2) ή/και **αναγνώριση ατόμων που μιλούν (diarization)**
7. *(Προαιρετικό)* Ενεργοποίηση **Lip Sync** (Wav2Lip)
8. Κάντε κλικ στο **Έναρξη μετάφρασης**

**Από το YouTube (ή οποιονδήποτε υποστηριζόμενο ιστότοπο):**
1. Επικολλήστε μία ή περισσότερες διευθύνσεις URL στο πεδίο **URL** (μία ανά γραμμή)
2. Διαμορφώστε τη γλώσσα, το μοντέλο και τη φωνή ως συνήθως
3. Κάντε κλικ στο **⬇ Λήψη & Μετάφραση**

> Το yt-dlp υποστηρίζει YouTube, Vimeo, Twitter/X, TikTok και [1000+ άλλους ιστότοπους](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md).

> ⚠️ **Ειδοποίηση δίκαιης χρήσης:** Η λήψη βίντεο μέσω yt-dlp θεωρείται αυτοματοποιημένη πρόσβαση από πλατφόρμες όπως το YouTube και ενδέχεται να παραβιάζει τους Όρους Παροχής Υπηρεσιών. Η βαριά ή επαναλαμβανόμενη χρήση από την ίδια διεύθυνση IP μπορεί να οδηγήσει σε προσωρινούς αποκλεισμούς (HTTP 429 / απαιτούνται σφάλματα σύνδεσης). Χρησιμοποιήστε ένα VPN ή περιστρέψτε την IP σας εάν αντιμετωπίσετε αποτυχίες λήψης. Αυτό το εργαλείο προορίζεται μόνο για προσωπική, μη εμπορική χρήση. Η αναδιανομή μεταφρασμένου περιεχομένου ενδέχεται να παραβιάζει τα πνευματικά δικαιώματα - να σέβεστε πάντα τα δικαιώματα του αρχικού δημιουργού.

### Μετάφραση σε πραγματικό χρόνο (υπότιτλοι και πειραματική μεταγλώττιση φωνής)

Παρακολουθήστε ένα τοπικό αρχείο ή έναν επιλυμένο σύνδεσμο βίντεο κατ' απαίτηση με μεταφρασμένους υπότιτλους και προαιρετική προφορική μετάφραση. Χρησιμοποιήστε τη γραμμή κάτω από τη συσκευή αναπαραγωγής:

**Από σύνδεσμο:**

1. Επικολλήστε έναν σύνδεσμο στο πεδίο **URL**
2. Ορίστε τη γλώσσα πηγής και προορισμού, επιλέξτε μια φωνή και προσαρμόστε το ρυθμιστικό **Καθυστέρηση**
3. Επιλέξτε **Μετεγγραφική φωνή** ή/και **Υπότιτλοι**
4. Για να ακούσετε μόνο τη μεταφρασμένη φωνή, επιλέξτε **Σίγαση αρχικού ήχου** πριν ξεκινήσετε (στα ιταλικά: **Silenzia originale**, δίπλα στο πλαίσιο ελέγχου υπότιτλων)
5. Κάντε κλικ στο **Μετάφραση σε πραγματικό χρόνο** - ο σύνδεσμος επιλύθηκε και η μετάφραση ξεκινά

**Από ένα φορτωμένο αρχείο:** φορτώστε ένα βίντεο στο πρόγραμμα αναπαραγωγής (Εισαγωγή -> Προσθήκη, μετά επιλέξτε το), αφήστε κενό το πεδίο URL, επιλέξτε τις ίδιες ζωντανές ρυθμίσεις και κάντε κλικ στην επιλογή **Μετάφραση σε πραγματικό χρόνο**. Μια διεύθυνση URL έχει προτεραιότητα όταν το πεδίο δεν είναι κενό.

- **Μηχανή:** MarianMT (εκτός σύνδεσης, προεπιλογή), Google, DeepL ή Ollama. Η αναγνώριση ομιλίας (Whisper) εκτελείται τοπικά. Τα μοντέλα εκτός σύνδεσης χρειάζονται μια αρχική λήψη.
- **Μετεγγραφή φωνής:** πειραματική αναπαραγωγή ομιλίας Edge-TTS μέσω μιας δεύτερης παρουσίας mpv. Απαιτεί πρόσβαση στο Διαδίκτυο και είναι ξεχωριστό από τη μαζική κλωνοποίηση φωνής.
- **Σίγαση αρχικού ήχου:** διαθέσιμο τόσο πριν από την έναρξη όσο και κατά τη διάρκεια της μετάφρασης. Σίγαει ολόκληρο το αρχικό soundtrack, συμπεριλαμβανομένης της μουσικής και των εφέ, αλλά αφήνει τη μεταφρασμένη φωνή να ακουστεί. Δεν απομονώνει το άτομο που μιλά στον αρχικό ήχο. Απενεργοποιήστε το για να επαναφέρετε το soundtrack. επαναφέρεται όταν τελειώσει η ζωντανή περίοδος λειτουργίας. Το κουμπί ηχείου της συσκευής αναπαραγωγής είναι η γενική σίγαση, όχι αυτό το ανεξάρτητο χειριστήριο.
- **Παύση και αναζήτηση:** Τα στοιχεία ελέγχου του προγράμματος αναπαραγωγής βίντεο είναι συνδεδεμένα στη ζωντανή περίοδο λειτουργίας. Ο συγχρονισμός ήχου από άκρο σε άκρο χρειάζεται ακόμα δοκιμές αποδοχής για συγκεκριμένη πλατφόρμα.
- **Τρέχοντα όρια:** ο χειρισμός επικάλυψης/εξασθένισης κλιπ, η βαθμονόμηση χρονισμού ήχου και η αποδοχή των Windows παραμένουν ανοιχτά. Οι αναπτυσσόμενες ζωντανές μεταδόσεις δεν υποστηρίζονται ακόμη. η ετικέτα της ζωντανής λειτουργίας δεν υποδηλώνει υποστήριξη για την απορρόφηση μιας εκπομπής καθώς αυτή μεγαλώνει. Δείτε την [κατάσταση υλοποίησης και υπολειπόμενη εργασία](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).

Για ένα αποθηκευμένο μεταγλωττισμένο βίντεο, χρησιμοποιήστε τη **Λήψη & Μετάφραση** / **Έναρξη μετάφρασης** αντί για την προεπισκόπηση σε πραγματικό χρόνο.

### δοκιμές ολοκλήρωσης με πραγματικά μοντέλα

Η προεπιλεγμένη σουίτα δοκιμής αποφεύγει τις πραγματικές λήψεις μοντέλων και τη μακρά εργασία GPU. Για να εκτελέσετε εμπειρικούς ελέγχους συμμετοχής για την εγκατεστημένη τοπική στοίβα:

```bash
VTAI_RUN_HEAVY_SMOKE=1 python -m unittest discover -s tests -p "test_heavy_smoke.py" -v
```

Αυτοί οι έλεγχοι επικυρώνουν πραγματικές εισαγωγές Wav2Lip, διαθεσιμότητα Torch CUDA, διαθεσιμότητα δαίμονα Ollama και faster-Whisper σε συνθετική ομιλία. Αποτυγχάνουν σκόπιμα ή παραλείπονται όταν η τοπική κατάσταση προγράμματος οδήγησης/δαίμονας/μοντέλου δεν είναι έτοιμη.

**Παραδείγματα:**

```bash
# Μεταφράστε ιταλικό βίντεο στα αγγλικά με την τοπική MarianMT
# (κατεβάζει το μοντέλο ~298 MB κατά την πρώτη χρήση και μετά είναι εντελώς εκτός σύνδεσης)
python video_translator_gui.py video.mp4 --lang-source it --lang-target en --translation-engine marian

# Μετάφραση με κλωνοποίηση φωνής + αναγνώριση ατόμων που μιλούν (diarization)
python video_translator_gui.py interview.mp4 --lang-target en --diarize --hf-token hf_xxx

# Μετάφραση με συγχρονισμό χειλιών
python video_translator_gui.py video.mp4 --lang-target en --lipsync

# Μόνο υπότιτλοι (χωρίς μεταγλώττιση φωνής)
python video_translator_gui.py video.mp4 --lang-target fr --subs-only
```

> Το `large-v3-turbo` είναι μια αποσταγμένη έκδοση του `large-v3` (4 στρώματα αποκωδικοποιητή έναντι 32) - σχεδόν μεγάλη ποιότητα σε ταχύτητα επιπέδου `medium`. Συνιστώμενη προεπιλογή σε μια σύγχρονη GPU όταν έχει σημασία η ταχύτητα μεταγραφής. Η πτώση της ποιότητας σε πολύγλωσσο υλικό είναι μικρή.

## Αυτόνομες μονάδες CLI

Το αρθρωτό πακέτο εκθέτει τέσσερα εργαλεία που απευθύνονται στον χρήστη, τα οποία μπορούν να κληθούν απευθείας χωρίς να ξεκινήσει η πλήρης διοχέτευση:

```bash
# Πριν από την πτήση ένα βίντεο για παρουσία προσώπου (το Wav2Lip θα παραλείπει εάν απουσιάζει).
python3 -m videotranslator.face_detector path/to/video.mp4
# έξοδος 0 = πρόσωπο παρόν, έξοδος 1 = χωρίς πρόσωπο

# Αναλύστε ένα *_metrics.csv που παράγεται από τον build_dubbed_track.
# Αναφορές P50/P75/P90/P95 του pre_stretch_ratio, ανάλυση ζώνης ακουστότητας,
# ελαστική χρήση του κινητήρα και τα κορυφαία-N χειρότερα ακραία σημεία με το κείμενο-στόχο τους.
python3 -m videotranslator.metrics_csv path/to/video_metrics.csv

# Εξυγίανση κειμένου για TTS (επαναγράφει άνω και κάτω τελείες, ερωτηματικά, έλλειψη, παύλες).
echo "alle 10:30 ho detto: andiamo!" | python3 -m videotranslator.tts_text_sanitizer

# Υπολογίστε τη δυσκολία μεταγλώττισης φωνής από ένα αρχείο τμημάτων .srt ή .json ΠΡΙΝ εκτελέσετε το TTS.
python3 -m videotranslator.difficulty_detector path/to/video_it.srt --target-lang it --expansion 1.25
```

Κάθε εργαλείο διαθέτει `-h`/`--help` για πλήρεις επιλογές. Είναι αυτόνομα και επαναχρησιμοποιούν τις ίδιες μονάδες στις οποίες βασίζεται ο αγωγός μεταγλώττισης φωνής, έτσι ώστε η έξοδος τους να παραμένει συνεπής με το χρόνο εκτέλεσης.
