Інструмент голосового дублювання відео на основі штучного інтелекту, який автоматично транскрибує, перекладає та дублює відео 26 мовами з локальними параметрами обробки та без ключів API, які потрібні за замовчуванням. Whisper розпізнавання мовлення виконується локально; Edge-TTS, Google Translate і DeepL потребують підключення до Інтернету. Додаткові функції (DeepL, ідентифікація людей, що говорять (діаризація)) можуть потребувати ключа API або маркера доступу.

> **v2.0** - модульний пакет, локальний переклад Ollama, оркестровка профілю якості, метадані Python, які можна встановити, і тести інтеграції з реальними моделями. Перегляньте [Випуски GitHub](https://github.com/HeartB1t/VideoTranslatorAI/releases) та історію комітів, щоб отримати повний список змін.

## Як це працює

1. **Транскрипція** - [faster-Whisper](https://github.com/SYSTRAN/faster-whisper) транскрибує аудіо (прискорене GPU)
2. **Поділ голосу/музики** - [Demucs](https://github.com/facebookresearch/demucs) ізолює вокал від фонової музики
3. **Переклад** - MarianMT (локальний, офлайн), Google Translate, DeepL Free або **Ollama LLM** (Qwen3, стислі переклади з урахуванням слотів)
4. **ідентифікація людей, які говорять (діаризація)** *(необов’язково)* - [pyannote-audio](https://github.com/pyannote/pyannote-audio) визначає, хто говорить у кожному сегменті
5. **дублювання голосу** - [Edge-TTS](https://github.com/rany2/edge-tts) (400+ голосів) або [Coqui XTTS v2](https://github.com/coqui-ai/TTS) (клонування голосу, для кожного мовця в розмові)
6. **Змішування** - дубльований голос, змішаний з оригінальною фоновою музикою
7. **Нормалізація** - остаточний звук нормалізовано до -23 LUFS (стандарт трансляції EBU R128)
8. **Lip Sync** *(опціонально)* - [Wav2Lip](https://github.com/Rudrabha/Wav2Lip) синхронізує рухи рота з дубльованим аудіо

## особливості

- 🖥️ Тематичний графічний інтерфейс (Tkinter) - командний рядок не потрібен; Теми Graphite, Slate, Light і Neon, кольори акцентів, розмір тексту та панелі налаштувань можна змінити, перетягнувши їх
- 🌍 **26 цільових мов** з кількома голосами для кожної мови
- 🌐 **UI на 26 мовах** - сам інтерфейс адаптується до вашої мови
- 🎬 **Підтримка YouTube і URL-адрес** - вставте будь-яке посилання на YouTube і перекладіть безпосередньо (на основі yt-dlp)
- ▶️ **Вбудований відеопрогравач** (libmpv/mpv) - кольорове керування транспортуванням, список відтворення, A/B оригінал і дубльоване аудіо, перемикання субтитрів, знімок, повний екран, відкрита папка
- ⏱️ **Переклад у реальному часі** - переглядайте локальний файл або вирішене посилання на відео на вимогу з перекладеними субтитрами та повзунком затримки у стилі YouTube; двигуни MarianMT / Google / DeepL / Ollama. Експериментальний голосовий дубляж використовує Edge-TTS і другий екземпляр mpv. Обробка голосового перекриття та прийняття реального аудіо/Windows ще триває; зростаючі прямі трансляції поки що не підтримуються. Перегляньте [статус реалізації в реальному часі](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).
- 🎵 Розділення голосу та музики через Demucs (зберігає фонову музику)
- 🔇 Функція **Вимкнути оригінальний звук**, доступна до та під час прямого перекладу, вимикає звукову доріжку відео, зберігаючи перекладений голос чутним. Вимкніть його, щоб відновити вихідний звук; він скидається після завершення сеансу.
- 🧠 **MarianMT** - повністю локальний офлайн-нейронний переклад (Helsinki-NLP, без обмежень на кількість запитів, без ключа API)
- 🤖 **Переклад Ollama LLM** *(новий у версії 2.0)* - локальний LLM (Qwen3, Llama, Mistral), який створює стислі переклади з урахуванням слотів для природного голосового дубляжу, автоматично визначає/встановлює/запускає/витягує модель під час першого використання
- 🎙️ **Клонування голосу** - Coqui XTTS v2 клонує особу, яка говорить голосом оригінального аудіо на цільовій мові (модель ~1,8 ГБ), з адаптивною швидкістю для кожного сегмента та багаторазовими повторними спробами галюцинацій
- 👥 **ідентифікація людей, які говорять (діаризація)** - pyannote-audio 3.1 ідентифікує кількох людей, які говорять; XTTS клонує кожен голос окремо
- 💋 **Lip Sync** - Wav2Lip GAN синхронізує рухи рота з дубльованим аудіо (модель ~416 МБ)
- 🔊 **Нормалізація аудіо** - автоматична нормалізація гучності -23 LUFS (EBU R128)
- ✏️ Редактор субтитрів - переглядайте та виправляйте субтитри перед голосовим дубляжем
- 📦 Пакетна обробка - перекладайте кілька відео або URL-адрес одночасно
- ⚡ Прискорення GPU через CUDA (автоматично повертається до CPU)
- 📄 Додатковий експорт субтитрів `.srt`
- 🔁 Механізм перекладу **DeepL Free** (необов’язково - 500 тис. символів/місяць, потрібен безкоштовний ключ API)
- 🔧 **Автовстановлення** - відсутні пакети Python і ffmpeg встановлюються автоматично під час першого запуску

Голосовий каталог Edge-TTS визначено в `LANGUAGES` у верхній частині `video_translator_gui.py`. Цей словник є джерелом істини для назв цільових мов, голосових перемикачів GUI та резервного голосу CLI, коли `--voice` опущено.

## Двигуни перекладу

| Двигун | Налаштування | Межі | якість |
|--------|-------|--------|---------|
| **Google Translate** *(за замовчуванням)* | Жодного | Неофіційне копіювання - може бути придушено для великих відео | ★★★★ |
| **MarianMT** | Немає - завантажує ~298 МБ на мовну пару під час першого використання | Немає - повністю офлайн після завантаження | ★★★★ |
| **DeepL Free** | Безкоштовний ключ API на [deepl.com](https://www.deepl.com/pro-api) | 500 тис. символів на місяць | ★★★★★ |
| **Ollama LLM** *(рекомендовано для голосового дубляжу - нове у v2.0)* | Автоматично встановлюється під час першого використання (модель Ollama ~1 ГБ + 5 ГБ) | Жодного - повністю локальний | ★★★★★ |

> **MarianMT** використовує моделі [Helsinki-NLP/opus-mt](https://huggingface.co/Helsinki-NLP), кешовані локально після першого завантаження. Потрібна чітка вихідна мова (автоматичне визначення не підтримується - виберіть вихідну мову вручну). Необхідні пакети Python (`sacremoses`, `sentencepiece`) встановлюються автоматично під час першого вибору, якщо їх немає.

> **Ollama LLM** *(нове у версії 2.0)* є рекомендованим механізмом для голосового дубляжу, оскільки він створює переклади з урахуванням цільового часового інтервалу. Там, де MarianMT перекладає буквально та створює італійську/іспанську/французьку приблизно на 25% довшу, ніж англійську (примусове звукове стиснення аудіо на TTS), LLM пропонує зберегти кожен сегмент лаконічним і природним для розмовної подачі, досягаючи типового співвідношення символів 0,85-0,95 проти джерела. Модель за замовчуванням - `qwen3:8b` (5,2 ГБ на диску, ~6 ГБ VRAM); `qwen3:4b` (~3 ГБ) - це полегшений варіант, `qwen3:14b` - якісніший. Конвеєр автоматично виявляє двійковий файл Ollama, автоматично встановлює його через офіційний інсталятор під час першого використання (зі спливаючим вікном згоди), запускає демон і витягує вибрану модель - ручне налаштування не потрібне. Автоматично перемикається на Google Translate, якщо чогось не вистачає.

## Клонування голосу (XTTS v2)

Якщо ввімкнено, програма витягує голос мовця з оригінального відео та використовує його як посилання для клонування голосу цільовою мовою.

- Підтримувані мови: AR, ZH, CS, DE, EN, ES, FR, HI, HU, IT, JA, KO, NL, PL, PT, RU, TR (17/26)
- Для решти 9 мов Edge-TTS використовується автоматично як запасний варіант
- Модель (~1,8 ГБ) автоматично завантажується під час першого використання на `~/.local/share/tts/`
- **Довідник із фільтром VAD** (версія 1.4): 10-15 с безперервного мовлення, вибраного з оригінального аудіо через [silero-vad](https://github.com/snakers4/silero-vad) для кращої якості клонування голосу
- **Швидкість генерації** можна налаштувати (`xtts_speed`, за замовчуванням `1.25`): вищі значення зменшують артефакти стиснення аудіо після обробки, коли перекладений текст довший за вихідний слот. Налаштування через `~/.config/videotranslatorai/config.json` або CLI `--xtts-speed`
- Працює на CUDA або CPU

## ідентифікація людей, що говорять (діаризація) (pyannote-audio)

Якщо ввімкнено, програма визначає, хто говорить у кожному сегменті. У поєднанні з клонуванням голосу голос кожного мовця клонується окремо, що ідеально підходить для інтерв’ю, подкастів і відео з кількома особами.

- Потрібен безкоштовний [токен HuggingFace](https://huggingface.co/settings/tokens) (одноразова реєстрація)
- **Токен надійно зберігається** (версія 1.4) через брелок ОС: Windows Credential Manager, macOS Keychain, Linux Secret Service. Автоматична міграція з попереднього сховища JSON у відкритому вигляді
- Після першого завантаження працює повністю в автономному режимі
- Модель: `pyannote/speaker-diarization-3.1`

## Синхронізація губ (Wav2Lip)

Якщо ввімкнено, програма застосовує Wav2Lip GAN, щоб синхронізувати рухи рота об’єкта з дубльованим аудіо - здається, що людина розмовляє мовою перекладу.

- Модель (~416 МБ) і сховище автоматично клонуються під час першого використання до `~/.local/share/wav2lip/`
- Працює на CUDA (рекомендовано) або CPU
- Значно збільшує час обробки
- Найкраще працює на відео з одним чітко видимим обличчям

## Вимоги

- Python 3.10+ (інсталятор Windows 3.11.9 налаштовує автоматично)
- Windows 10/11 (x64), Linux або macOS
- **Наполегливо рекомендується NVIDIA GPU** - див. таблицю GPU нижче
- 20 ГБ вільного місця на диску для повної інсталяції (PyTorch CUDA, Whisper large-v3, XTTS, Wav2Lip)

> **ffmpeg і всі пакети Python встановлюються автоматично** під час першого запуску, якщо вони відсутні. Ручне налаштування не потрібно.

**Додаткова системна залежність** - `rubberband-cli` (Linux: `sudo apt install rubberband-cli`, macOS: `brew install rubberband`). Після встановлення він використовується для розтягування часу зі збереженням висоти в контрольованому профілем діапазоні якості (за замовчуванням 1,15-1,50, до 1,65 для жорсткого вмісту), усуваючи залишковий ефект «бурундука» на клонованих голосах XTTS. Без нього конвеєр працює без змін (автоматичний відкат до ffmpeg `atempo`). Профілі якості тепер віддають перевагу додатковим коротким повторним спробам перекладу над екстремальним прискоренням звуку.

### Підтримка GPU

Конвеєр використовує п’ять компонентів із прискоренням GPU (faster-whisper, Demucs, XTTS, Wav2Lip, pyannote). Покриття GPU неоднакове для різних постачальників:

| GPU | Windows | Linux | Примітки |
|-----|---------|-------|-------|
| **NVIDIA** (RTX 20xx або новіша, драйвер CUDA 12.4) | ✅ повний розгін | ✅ повний розгін | **Рекомендовано.** Усі 5 компонентів працюють на GPU. |
| **AMD** (Radeon) | ⚠️ неповний (DirectML не підтримує XTTS і faster-whisper) | ⚠️ частково (ROCm працює для Demucs/XTTS/pyannote, але faster-whisper підтримує лише CUDA) | Працює, але транскрипція Whisper залишається на ЦП і домінує над загальним часом. |
| **Intel Arc** | ⚠️ незріла підтримка PyTorch XPU | ⚠️ те саме | Не перевірено. |
| **Немає (лише ЦП)** | ✅ працює | ✅ працює | Очікуйте, що **10-20× повільніше**, ніж у реальному часі. Для транскрибування 5-хвилинного кліпу може знадобитися більше 50 хвилин за допомогою Whisper large-v3. |

**Рекомендована відеопам'ять NVIDIA:**

| VRAM | Приклади відеокарт | Досвід |
|------|---------------|-----------|
| 6 ГБ | GTX 1660, RTX 2060 | Можна використовувати, не можна запускати XTTS + Wav2Lip одночасно |
| 8 ГБ | RTX 3060 Ti, 4060 | Повний конвеєр, без маржі |
| **12 ГБ+** | **RTX 3060 12 ГБ, 4070, 4080** | **Рекомендовано - зручно** |
| 24 ГБ | RTX 3090, 4090 | Резервна ємність для великих партій |

## монтаж

### Windows

1. Клонуйте або завантажте це сховище
2. Клацніть правою кнопкою миші `setup_windows.bat` → **Запуск від імені адміністратора** → меню показує `[1] Install`
3. Інсталятор автоматично:
   - Встановлює Python 3.11, якщо його немає (для всієї системи)
   - Встановлює Git for Windows, якщо його немає
   - Встановлює всі залежності Python (PyTorch CUDA 12.4, faster-whisper, Demucs, coqui-tts, Wav2Lip deps тощо)
   - Завантажує та встановлює ffmpeg
   - Встановлює вбудований відеопрогравач (python-mpv плюс збірка libmpv у `mpv-runtime`). Цей крок необов’язковий: якщо він не вдається, все інше працює, а на панелі програвача пояснюється, чого не вистачає
   - Створює **загальний ярлик на робочому столі** (видимий для кожного облікового запису Windows на ПК)

> Інсталятор є **багатокористувацьким**: усе встановлюється для всієї системи під `%ProgramFiles%\VideoTranslatorAI`, і будь-який користувач Windows на машині знаходить ярлик, готовий до роботи. Інструменти збірки VS C++ **більше не потрібні** - підтримуваний форк `coqui-tts` надає попередньо скомпільовані пакети колеса Python.

# Необов’язково: установіть проект як редагований пакет Python

## Видалити

### Windows

Запустіть `setup_windows.bat` (клацніть правою кнопкою миші → **Запуск від імені адміністратора**) і виберіть `[3] Uninstall` у меню. Пропонуються три підрежими видалення:

| Режим | Потрібен адміністратор | Область застосування |
|------|----------------|-------|
| **[1] Повне видалення - одним клацанням миші** | ✅ | Видаляє папку програми, ярлик загальнодоступного робочого столу, ffmpeg зі ШЛЯХУ комп’ютера, кеш моделі HF кожного користувача (Whisper/XTTS) і конфігурацію (`HF token`), а також усі пакети Python AI, встановлені інсталятором. Наприкінці він також запитує (увімкнути), чи видаляти **Python 3.11** і **Git for Windows** за допомогою рядків тихого видалення реєстру. |
| **[2] Лише поточний користувач** | ❌ | Видаляє лише конфігурацію VTAI запущеного користувача, кеш HF/XTTS і застарілу інсталяцію для кожного користувача. **Залишає загальносистемну інсталяцію без змін**, щоб інші облікові записи Windows на ПК могли продовжувати використовувати програму. |
| **[3] Custom - granular** | ✅ для системних елементів, ❌ для елементів користувача | Запит Y/N для кожної категорії: папка програми, ярлик, ШЛЯХ до комп’ютера, застарілі встановлення для кожного користувача, конфігурації/кеші для кожного користувача, потім згруповані пакети Python (TTS, стек PyTorch, Whisper+ctranslate2, Demucs, Wav2Lip deps, pyannote, конвеєрні утиліти) і, нарешті, додаткові утиліти Python 3.11 і Git. |

## Використання

### діагностика

```bash
python video_translator_gui.py --preflight
python video_translator_gui.py --preflight --preflight-lipsync
python video_translator_gui.py --preflight --preflight-player
python -m videotranslator --preflight
```

Запускає діагностику локального середовища без запуску перекладу чи інсталяції. `--preflight-lipsync` обробляє пакети обличчя Wav2Lip за потреби, що корисно перед увімкненням **Lip Sync**. Графічний інтерфейс надає ту саму базову перевірку за допомогою кнопки **Діагностика** панелі журналу. `--preflight-player` обробляє інтегрований відеопрогравач (python-mpv і завантажуваний libmpv) відповідно до потреб. `python -m videotranslator.libmpv_runtime check` досліджує лише libmpv (вихід 0 готовий, 2 недоступний).

### GUI

```bash
python video_translator_gui.py
```

**Макет:** параметри пакетного перекладу розміщені в стовпці праворуч у вигляді набору панелей налаштувань: **Введення**, **Переклад**, **Профіль робочого циклу**, **Початок** і розширені розділи, що згортаються (модель, механізм перекладу, аудіо, клонування голосу, синхронізація губ, діаризація, параметри, гарячі слова). Велика область ліворуч - це **інтегрований відеопрогравач** (транспорт, список відтворення, оригінал A/B або дубльоване аудіо, субтитри, знімок, повноекранний режим) із панеллю **перекладу в реальному часі** під ним. Перетягніть картку за її заголовок або за ручку **≡**, щоб перемістити її вгору або вниз по стовпцю; порядок зберігається (`ui_panel_order`) і відновлюється під час наступного запуску. Панель журналу внизу можна приховати за допомогою **Сховати журнал**. Під час запуску вікно відкривається в центрі поточного монітора (той, що знаходиться під вказівником) і розгорнуто, тому воно добре поводиться під час налаштування кількох моніторів.

**Керування відеоплеєром:** значки використовують узгоджені функціональні кольори в кожній темі, незалежно від вибраного кольору акценту:

| контроль | Колір |
|---------|--------|
| Відтворити відео | Зелений |
| Пауза (замінює відтворення під час відтворення) | Бурштин |
| Зупинити відтворення | Коралово-червоний |
| Попередній / назад 10 с / вперед 10 с / наступний | Синій |
| знімок | Фіалка |
| Відкрити папку | золото |

Наведення курсора додає тонкий тонований фон. Недоступні елементи керування нейтральні; навігація списком відтворення залишається доступною після зупинки. Підказки та індикатори фокусування клавіатури залишаються доступними, тому колір - не єдиний спосіб визначення дій.

**З локальних файлів:**
1. Натисніть **Додати**, щоб вибрати один або кілька відеофайлів
2. Виберіть вихідну та цільову мову
3. Відкрийте розділ **Модель** і виберіть модель Whisper (`small` - хороший баланс швидкості та точності)
4. Виберіть голос і за потреби налаштуйте швидкість TTS
5. *(Необов’язково)* У **системі перекладу** виберіть **Google** (за умовчанням), **MarianMT** (локальний/офлайн), **DeepL Free** або **Ollama LLM** (локальний, рекомендовано для голосового дубляжу)
6. *(Необов’язково)* Увімкніть **Клонування голосу** (XTTS v2) та/або **ідентифікацію людей, що говорять (діаризація)**
7. *(Додатково)* Увімкнути **Lip Sync** (Wav2Lip)
8. Натисніть **Почати переклад**

**З YouTube (або будь-якого підтримуваного сайту):**
1. Вставте одну або кілька URL-адрес у поле **URL** (по одній на рядок)
2. Налаштуйте мову, модель і голос як зазвичай
3. Натисніть **⬇ Завантажити та перекласти**

> yt-dlp підтримує YouTube, Vimeo, Twitter/X, TikTok і [1000+ інших сайтів](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md).

> ⚠️ **Повідомлення про добросовісне використання:** Завантаження відео через yt-dlp вважається автоматичним доступом на таких платформах, як YouTube, і може порушувати їхні Умови використання. Інтенсивне або багаторазове використання з однієї IP-адреси може призвести до тимчасового блокування (HTTP 429 / помилки, необхідні для входу). Використовуйте VPN або змініть свою IP-адресу, якщо виникнуть помилки завантаження. Цей інструмент призначений лише для особистого, некомерційного використання. Повторне розповсюдження перекладеного вмісту може порушувати авторські права - завжди поважайте права оригінального творця.

### Переклад у реальному часі (субтитри та експериментальний голосовий дубляж)

Перегляньте локальний файл або вирішене посилання на відео на вимогу з перекладеними субтитрами та необов’язковим голосовим перекладом. Використовуйте панель під плеєром:

**За посиланням:**

1. Вставте посилання в поле **URL**
2. Встановіть вихідну та цільову мову, виберіть голос і налаштуйте повзунок **Затримка**
3. Виберіть **Дубльований голос** і/або **Субтитри**
4. Щоб почути лише перекладений голос, виберіть **Вимкнути оригінальний звук** перед початком (італійською: **Silenzia originale**, поруч із прапорцем субтитрів)
5. Натисніть **Перекласти в режимі реального часу** - посилання буде розкрито та розпочнеться переклад

**Із завантаженого файлу:** завантажте відео в програвач (Введення -> Додати, потім виберіть його), залиште поле URL-адреси порожнім, виберіть ті самі налаштування прямого ефіру та натисніть **Перекласти в реальному часі**. URL-адреса має пріоритет, якщо поле не пусте.

- **Двигун:** MarianMT (офлайн, за умовчанням), Google, DeepL або Ollama. Розпізнавання мовлення (Whisper) працює локально. Офлайн-моделі потребують початкового завантаження.
- **Голосовий дубляж:** експериментальне відтворення мовлення Edge-TTS через другий екземпляр mpv. Для цього потрібен доступ до Інтернету, і це окремо від пакетного клонування голосу.
- **Вимкнути оригінальний звук:** доступно як перед початком перекладу, так і під час нього. Він заглушає весь оригінальний саундтрек, включаючи музику та ефекти, але залишає перекладений голос чутним. Це не ізолює особу, яка говорить в оригінальному аудіо. Вимкніть його, щоб відновити звукову доріжку; він скидається після завершення сеансу. Кнопка динаміка плеєра - це загальне відключення звуку, а не окреме керування.
- **Пауза та пошук:** елементи керування відеоплеєром підключено до сеансу в реальному часі; наскрізна аудіосинхронізація все ще потребує приймальних тестів на платформі.
- **Поточні обмеження:** обробка накладання/згасання кліпів, калібрування аудіосинхронізації та прийняття Windows залишаються відкритими. Зростаючі прямі трансляції поки що не підтримуються; мітка режиму прямого ефіру не передбачає підтримки прийому трансляції в міру її зростання. Перегляньте [статус впровадження та роботу, що залишилася](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).

Для збереженого дубльованого відео використовуйте **Завантажити та перекласти** / **Почати переклад** замість попереднього перегляду в реальному часі.

### Блоки механізму перекладу та VPN

Можуть статися два різні блоки з різними виправленнями:

| Блокувати | Симптом | Виправити |
|-------|---------|-----|
| **Завантажити** (yt-dlp) | «Увійдіть, щоб підтвердити, що ви не бот», HTTP 429 | **VPN** / змінити IP-адресу або увійти на YouTube у своєму браузері (файли cookie зчитуються автоматично) |
| **Переклад** (безкоштовна кінцева точка Google) | "Google Translate не вдалося перекласти... частота запитів обмежена/заблоковано" | Використовуйте **MarianMT** (офлайн) або **Ollama** (локальний) - без обмеження кількості запитів. VPN також допомагає. Пакетний потік тепер **автоматично повертається до MarianMT**, коли Google блокується. |

### Теми і зовнішній вигляд

Натисніть значок шестірні в заголовку, щоб відкрити **Налаштування**:

- **Тема**: Автоматично (слідує темному/світлому режиму ОС), Graphite (за замовчуванням), Slate, Light, Neon.
- **Колір акценту**: за умовчанням для кожної теми або синій, бірюзовий, фіолетовий, зелений, бурштиновий, рожевий.

Зміни застосовуються негайно, без перезапуску, і зберігаються у файлі конфігурації (`ui_theme`, `ui_accent`, `ui_scale`, `ui_lang`). **Відновити налаштування за замовчуванням** повертає тему Graphite, акцент за замовчуванням, звичайний розмір тексту та порядок панелей налаштувань за замовчуванням.

## Інтерфейс команди автономних модулів

Модульний пакет надає чотири призначені для користувача інструменти, які можна викликати безпосередньо без запуску повного конвеєра:

```bash
# Відео перед польотом для присутності обличчя (Wav2Lip пропустить, якщо його немає).
python3 -m videotranslator.face_detector path/to/video.mp4
# вихід 0 = обличчя є, вихід 1 = обличчя немає

# Проаналізуйте *_metrics.csv, створений build_dubbed_track.
# Звіти P50/P75/P90/P95 pre_stretch_ratio, розбивка діапазону чутності,
# використання розширеного двигуна та перші N найгірших викидів із їхнім цільовим текстом.
python3 -m videotranslator.metrics_csv path/to/video_metrics.csv

# Очистити текст для TTS (переписує двокрапки, крапки з комою, крапки, тире).
echo "alle 10:30 ho detto: andiamo!" | python3 -m videotranslator.tts_text_sanitizer

# Оцініть складність голосового дубляжу з файлу сегментів .srt або .json ПЕРЕД запуском TTS.
python3 -m videotranslator.difficulty_detector path/to/video_it.srt --target-lang it --expansion 1.25
```

Кожен інструмент має `-h`/`--help` для повних опцій. Вони є самодостатніми та повторно використовують ті самі модулі, на яких покладається конвеєр голосового дубляжу, тому їхній результат залишається узгодженим із часом виконання.
