أداة دبلجة صوت الفيديو المدعومة بالذكاء الاصطناعي والتي تقوم تلقائيًا بنسخ مقاطع الفيديو وترجمتها وإعادة دبلجتها إلى 26 لغة، مع خيارات معالجة محلية ولا يلزم وجود مفاتيح API افتراضيًا. يتم تشغيل التعرف على الكلام Whisper محليًا؛ تتطلب Edge-TTS وGoogle Translate وDeepL اتصالاً بالإنترنت. قد تتطلب الميزات الاختيارية (DeepL، تحديد الأشخاص المتحدثين (تمييز المتحدثين)) مفتاح واجهة برمجة التطبيقات (API) أو رمز الوصول.

> **الإصدار 2.0** - حزمة معيارية، وترجمة Ollama المحلية، وتنسيق ملف تعريف الجودة، وبيانات تعريف Python القابلة للتثبيت، واختبارات التكامل الاختيارية مع النماذج الحقيقية. راجع [إصدارات GitHub](https://github.com/HeartB1t/VideoTranslatorAI/releases) وسجل الالتزام للحصول على القائمة الكاملة للتغييرات.

## كيف يعمل

1. **النسخ** - يقوم [faster-Whisper](https://github.com/SYSTRAN/faster-whisper) بنسخ الصوت (تسريع وحدة معالجة الرسومات)
2. **فصل الصوت/الموسيقى** - يقوم [Demucs](https://github.com/facebookresearch/demucs) بعزل الغناء عن موسيقى الخلفية
3. **الترجمة** - MarianMT (محلي، غير متصل بالإنترنت)، Google Translate، DeepL Free، أو **Ollama LLM** (Qwen3، ترجمات موجزة مدركة للفتحات)
4. **تحديد هوية الأشخاص المتحدثين (تمييز المتحدثين)** *(اختياري)* - يحدد [pyannote-audio](https://github.com/pyannote/pyannote-audio) من يتحدث في كل مقطع
5. **الدبلجة الصوتية** - [Edge-TTS](https://github.com/rany2/edge-tts) (أكثر من 400 صوت) أو [Coqui XTTS v2](https://github.com/coqui-ai/TTS) (استنساخ الصوت، لكل متحدث في المحادثة)
6. **الخلط** - تم مزج الصوت المدبلج مع موسيقى الخلفية الأصلية
7. **التطبيع** - تمت تسوية الصوت النهائي إلى -23 LUFS (معيار البث EBU R128)
8. **مزامنة الشفاه** *(اختياري)* - يقوم [Wav2Lip](https://github.com/Rudrabha/Wav2Lip) بمزامنة حركات الفم مع الصوت المدبلج

## الميزات

- 🖥️ واجهة المستخدم الرسومية (Tkinter) تحت عنوان - لا حاجة لسطر الأوامر؛ سمات Graphite وSlate وLight وNeon وألوان التمييز وحجم النص ولوحات الإعدادات التي يمكنك إعادة ترتيبها عن طريق السحب
- 🌍 **26 لغة مستهدفة** بأصوات متعددة لكل لغة
- 🌐 **واجهة المستخدم بـ 26 لغة** - تتكيف الواجهة نفسها مع لغتك
- 🎬 **دعم YouTube وURL** - الصق أي رابط على YouTube وقم بترجمته مباشرةً (بدعم من yt-dlp)
- ◀️ **مشغل فيديو متكامل** (libmpv/mpv) - عناصر تحكم في النقل مرمزة بالألوان، وقائمة تشغيل، وصوت A/B الأصلي مقابل الصوت المدبلج، وتبديل الترجمات، واللقطة، وملء الشاشة، وفتح المجلد
- ⏱️ **ترجمة فورية** - شاهد ملفًا محليًا أو رابط فيديو تم حله عند الطلب مع ترجمة مترجمة وشريط تمرير تأخير على نمط YouTube؛ محركات MarianMT / Google / DeepL / Ollama. تستخدم الدبلجة الصوتية التجريبية Edge-TTS ومثيل mpv ثانٍ. لا تزال معالجة تداخل الصوت وقبول الصوت/Windows الحقيقي قيد التقدم؛ لا يتم دعم عمليات البث المباشر المتزايدة حتى الآن. راجع [حالة التنفيذ المباشر](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).
- 🎵 فصل الصوت/الموسيقى عبر Demucs (يحتفظ بالموسيقى الخلفية)
- 🔇 **كتم الصوت الأصلي**، المتوفر قبل وأثناء الترجمة المباشرة، يعمل على كتم صوت الفيديو مع إبقاء الصوت المترجم مسموعًا. قم بإيقاف تشغيله لاستعادة الصوت الأصلي؛ يتم إعادة تعيينه عند انتهاء الجلسة المباشرة.
- 🧠 **MarianMT** - ترجمة عصبية محلية بالكامل وغير متصلة بالإنترنت (Helsinki-NLP، لا توجد حدود لمعدل الطلب، ولا يوجد مفتاح API)
- 🤖 **ترجمة Ollama LLM** *(جديد في الإصدار 2.0)* - LLM محلي (Qwen3، Llama، Mistral) ينتج ترجمات موجزة مدركة للفتحات لدبلجة الصوت الطبيعية، نموذج الاكتشاف التلقائي/التثبيت/التشغيل/السحب عند الاستخدام الأول
- 🎙️ **استنساخ الصوت** - يقوم Coqui XTTS v2 باستنساخ الشخص الذي يتحدث بصوت الصوت الأصلي باللغة المستهدفة (~نموذج 1.8 جيجابايت)، مع سرعة تكيف لكل مقطع وإعادة المحاولة متعددة البذور للهلوسة
- 👥 **تحديد هوية الأشخاص المتحدثين (تمييز المتحدثين)** - يحدد pyannote-audio 3.1 عدة أشخاص يتحدثون؛ يقوم XTTS باستنساخ كل صوت على حدة
- 💋 **Lip Sync** - يقوم Wav2Lip GAN بمزامنة حركات الفم مع الصوت المدبلج (~416 ميجا بايت نموذج)
- 🔊 **تطبيع الصوت** - ضبط جهارة الصوت تلقائيًا -23 LUFS (EBU R128)
- ✏️ محرر الترجمة - مراجعة الترجمة وتصحيحها قبل الدبلجة الصوتية
- 📦 المعالجة المجمعة - ترجمة مقاطع فيديو أو عناوين URL متعددة مرة واحدة
- ⚡ تسريع GPU عبر CUDA (يعود إلى وحدة المعالجة المركزية تلقائيًا)
- 📄 تصدير الترجمة الاختيارية `.srt`
- 🔁 **DeepL Free** محرك ترجمة (اختياري - 500 ألف حرف/شهر، يتطلب مفتاح API مجاني)
- 🔧 **التثبيت التلقائي** - يتم تثبيت حزم Python وffmpeg المفقودة تلقائيًا عند التشغيل لأول مرة

## محركات الترجمة

| المحرك | الإعداد | حدود | الجودة |
|--------|-------|--------|---------|
| **Google Translate** *(افتراضي)* | لا شيء | التجريد غير الرسمي - قد يتم تقييده في مقاطع الفيديو الكبيرة | ★★★★ |
| **MarianMT** | لا شيء - يتم التنزيل بحوالي 298 ميجابايت لكل زوج لغوي عند الاستخدام الأول | لا شيء - غير متصل بالإنترنت بشكل كامل بعد التنزيل | ★★★★ |
| **DeepL Free** | مفتاح API مجاني على [deepl.com](https://www.deepl.com/pro-api) | 500 ألف حرف/شهر | ★★★★★ |
| **Ollama LLM** *(موصى به للدبلجة الصوتية - الجديد في الإصدار 2.0)* | يتم تثبيته تلقائيًا عند الاستخدام الأول (~1 جيجابايت طراز Ollama + 5 جيجابايت) | لا شيء - محلي بالكامل | ★★★★★ |

> **MarianMT** يستخدم نماذج [Helsinki-NLP/opus-mt](https://huggingface.co/Helsinki-NLP)، المخزنة مؤقتًا محليًا بعد التنزيل الأول. يتطلب لغة مصدر واضحة (الاكتشاف التلقائي غير مدعوم - حدد لغة المصدر يدويًا). يتم تثبيت حزم Python المطلوبة (`sacremoses`، `sentencepiece`) تلقائيًا عند التحديد الأول في حالة فقدانها.

> **Ollama LLM** *(الجديد في الإصدار 2.0)* هو المحرك الموصى به للدبلجة الصوتية لأنه ينتج ترجمات تدرك الفترة الزمنية المستهدفة. حيث تترجم MarianMT حرفيًا وتنتج الإيطالية / الإسبانية / الفرنسية أطول بنسبة 25٪ تقريبًا من الإنجليزية (مما يفرض ضغطًا صوتيًا مسموعًا على تحويل النص إلى كلام)، يُطلب من LLM إبقاء كل مقطع موجزًا ​​وطبيعيًا للتسليم المنطوق، وتحقيق نسبة أحرف نموذجية تبلغ 0.85-0.95 مقابل المصدر. النموذج الافتراضي هو `qwen3:8b` (5.2 جيجابايت على القرص، ~ 6 جيجابايت VRAM)؛ `qwen3:4b` (~ 3 جيجابايت) هو الخيار خفيف الوزن، `qwen3:14b` هو الخيار الأعلى جودة. يكتشف خط الأنابيب تلقائيًا برنامج Ollama الثنائي، ويقوم بتثبيته تلقائيًا عبر برنامج التثبيت الرسمي عند الاستخدام الأول (مع نافذة منبثقة للموافقة)، ويبدأ البرنامج الخفي ويسحب النموذج المختار - لا يتطلب أي إعداد يدوي. يتحول تلقائيًا إلى Google Translate في حالة فقدان أي شيء.

## استنساخ الصوت (XTTS v2)

عند التمكين، يستخرج التطبيق صوت المتحدث من الفيديو الأصلي ويستخدمه كمرجع لاستنساخ الصوت في اللغة المستهدفة.

- اللغات المدعومة: AR، ZH، CS، DE، EN، ES، FR، HI، HU، IT، JA، KO، NL، PL، PT، RU، TR (17/26)
- بالنسبة للغات التسع المتبقية، يتم استخدام Edge-TTS تلقائيًا كبديل
- تم تنزيل النموذج (~1.8 جيجابايت) تلقائيًا عند الاستخدام الأول إلى `~/.local/share/tts/`
- **مرجع تمت تصفيته VAD** (الإصدار 1.4): 10-15 ثانية من الكلام المستمر المحدد من الصوت الأصلي عبر [silero-vad](https://github.com/snakers4/silero-vad) للحصول على جودة أفضل لاستنساخ الصوت
- **سرعة التوليد** قابلة للتكوين (`xtts_speed`، `1.25` الافتراضي): تعمل القيم الأعلى على تقليل تأثيرات ضغط الصوت بعد المعالجة عندما يكون النص المترجم أطول من فتحة المصدر. قم بالضبط عبر `~/.config/videotranslatorai/config.json` أو CLI `--xtts-speed`
- يعمل على CUDA أو وحدة المعالجة المركزية

## تحديد هوية الأشخاص المتحدثين (تمييز المتحدثين) (pyannote-audio)

عند التمكين، يحدد التطبيق من يتحدث في كل مقطع. بالاشتراك مع استنساخ الصوت، يتم استنساخ صوت كل متحدث بشكل منفصل - وهو مثالي للمقابلات والبودكاست ومقاطع الفيديو متعددة الأشخاص.

- يتطلب [رمز HuggingFace](https://huggingface.co/settings/tokens) مجانًا (التسجيل لمرة واحدة)
- **الرمز المُخزن بشكل آمن** (الإصدار 1.4) عبر حلقة مفاتيح نظام التشغيل: Windows Credential Manager، macOS Keychain، Linux Secret Service. الترحيل التلقائي من تخزين JSON للنص العادي السابق
- بعد التنزيل الأول، يعمل بشكل كامل دون اتصال بالإنترنت
- الموديل: `pyannote/speaker-diarization-3.1`

## مزامنة الشفاه (Wav2Lip)

عند التمكين، يطبق التطبيق Wav2Lip GAN لمزامنة حركات فم الشخص مع الصوت المدبلج - يبدو أن الشخص يتحدث اللغة المترجمة.

- تم استنساخ النموذج (~416 ميجابايت) والريبو تلقائيًا عند الاستخدام الأول إلى `~/.local/share/wav2lip/`
- يعمل على CUDA (مستحسن) أو وحدة المعالجة المركزية
- يزيد من وقت المعالجة بشكل ملحوظ
- يعمل بشكل أفضل مع مقاطع الفيديو التي تحتوي على وجه واحد واضح المعالم

## المتطلبات

- Python 3.10+ (يوفر مثبت Windows 3.11.9 تلقائيًا)
- نظام التشغيل Windows 10 / 11 (x64) أو Linux أو macOS
- **يوصى بشدة باستخدام NVIDIA GPU** - راجع جدول GPU أدناه
- مساحة خالية على القرص تبلغ 20 جيجابايت للتثبيت الكامل (PyTorch CUDA، Whisper Large-v3، XTTS، Wav2Lip)

> **يتم تثبيت ffmpeg وجميع حزم Python تلقائيًا** عند التشغيل لأول مرة في حالة فقدانها. لا يلزم الإعداد اليدوي.

**تبعية النظام الاختيارية** - `rubberband-cli` (Linux: `sudo apt install rubberband-cli`، macOS: `brew install rubberband`). عند تثبيته، يتم استخدامه لتمديد الوقت للحفاظ على طبقة الصوت في نطاق الجودة الذي يتم التحكم فيه بواسطة ملف التعريف (الافتراضي 1.15-1.50، حتى 1.65 للمحتوى الصلب)، وإزالة تأثير "السنجاب" المتبقي على أصوات XTTS المستنسخة. يعمل خط الأنابيب دون تغيير بدونه (الرجوع التلقائي إلى ffmpeg `atempo`). تفضل ملفات تعريف الجودة الآن عمليات إعادة محاولة الترجمة القصيرة الإضافية بدلاً من تسريع الصوت بشكل كبير.

### دعم GPU

يستخدم خط الأنابيب خمسة مكونات تسريع GPU (faster-whisper، Demucs، XTTS، Wav2Lip، pyannote). تغطية GPU ليست موحدة عبر البائعين:

| GPU | Windows | Linux | ملاحظات |
|-----|---------|-------|-------|
| **NVIDIA** (RTX 20xx أو الأحدث، برنامج تشغيل CUDA 12.4) | ✅ التسارع الكامل | ✅ التسارع الكامل | **موصى به.** تعمل جميع المكونات الخمسة على وحدة معالجة الرسومات. |
| **أيه إم دي** (راديون) | ⚠️ غير مكتمل (DirectML لا يدعم XTTS وfaster-whisper) | ⚠️ جزئي (يعمل ROCm مع Demucs/XTTS/pyannote لكن faster-whisper يدعم CUDA فقط) | يعمل ولكن يظل النسخ Whisper على وحدة المعالجة المركزية ويهيمن على إجمالي الوقت. |
| **Intel Arc** | ⚠️ دعم PyTorch XPU غير الناضج | ⚠️ نفسه | لم يتم اختباره. |
| **لا شيء (وحدة المعالجة المركزية فقط)** | ✅ يعمل | ✅ يعمل | توقع **10-20× أبطأ** من الوقت الفعلي. قد يستغرق مقطع مدته 5 دقائق أكثر من 50 دقيقة فقط للنسخ باستخدام Whisper Large-v3. |

**NVIDIA VRAM الموصى بها:**

| VRAM | أمثلة على بطاقات الرسوميات | الخبرة |
|------|---------------|-----------|
| 6 جيجابايت | جي تي إكس 1660، آر تي إكس 2060 | قابل للاستخدام، ولا يمكن تشغيل XTTS + Wav2Lip بشكل متزامن |
| 8 جيجا | آر تي إكس 3060 تي آي، 4060 | خط أنابيب كامل، لا يوجد هامش |
| **12 جيجابايت+** | **آر تي إكس 3060 12 جيجابايت، 4070، 4080** | **موصى به - مريح** |
| 24 جيجابايت | آر تي إكس 3090، 4090 | القدرة الاحتياطية للدفعات الكبيرة |

## التثبيت

### Windows

1. استنساخ أو تنزيل هذا المستودع
2. انقر بزر الماوس الأيمن فوق `setup_windows.bat` → **تشغيل كمسؤول** → تظهر القائمة `[1] Install`
3. المثبت تلقائيا:
   - تثبيت Python 3.11 إن لم يكن موجودًا (على مستوى النظام)
   - تثبيت Git for Windows إذا لم يكن موجودًا
   - تثبيت جميع تبعيات Python (PyTorch CUDA 12.4، faster-whisper، Demucs، coqui-tts، Wav2Lip deps، وما إلى ذلك)
   - تنزيل وتثبيت ffmpeg
   - تثبيت مشغل الفيديو المدمج (python-mpv بالإضافة إلى إصدار libmpv في `mpv-runtime`). الخطوة اختيارية: إذا فشلت، فكل شيء آخر يعمل ويوضح جزء المشغل ما هو مفقود
   - إنشاء **اختصار لسطح المكتب العام** (مرئي لكل حساب Windows على جهاز الكمبيوتر)

> برنامج التثبيت **متعدد المستخدمين**: يتم تثبيت كل شيء على مستوى النظام ضمن `%ProgramFiles%\VideoTranslatorAI` وأي مستخدم يعمل بنظام Windows على الجهاز يجد الاختصار جاهزًا للاستخدام. أدوات البناء VS C++ **لم تعد مطلوبة** - توفر شوكة `coqui-tts` التي تمت صيانتها حزم عجلة Python المترجمة مسبقًا.

## إلغاء التثبيت

### Windows

قم بتشغيل `setup_windows.bat` (انقر بزر الماوس الأيمن → **تشغيل كمسؤول**) واختر `[3] Uninstall` من القائمة. يتم تقديم ثلاثة أوضاع فرعية لإلغاء التثبيت:

| الوضع | مطلوب المشرف | النطاق |
|------|----------------|-------|
| **[1] إلغاء التثبيت بالكامل - بنقرة واحدة** | ✅ | يزيل مجلد التطبيق، واختصار سطح المكتب العام، وffmpeg من PATH للجهاز، وذاكرة التخزين المؤقت لنموذج HF لكل مستخدم (Whisper/XTTS) والتكوين (`HF token`)، وجميع حزم Python AI المثبتة بواسطة المثبت. في النهاية، يسأل أيضًا (الاشتراك) ما إذا كان سيتم إلغاء تثبيت **Python 3.11** و **Git for Windows** بصمت عبر سلاسل إلغاء التثبيت الهادئة في السجل الخاص بهم. |
| **[2] المستخدم الحالي فقط** | ❌ | يزيل فقط تكوين VTAI الخاص بالمستخدم قيد التشغيل، وذاكرة التخزين المؤقت HF/XTTS، والتثبيت القديم لكل مستخدم. **يترك التثبيت على مستوى النظام سليمًا** حتى تتمكن حسابات Windows الأخرى الموجودة على جهاز الكمبيوتر من الاستمرار في استخدام التطبيق. |
| **[3] مخصص - تفصيلي** | ✅ لعناصر النظام، ❌ لعناصر المستخدم | المطالبة Y/N لكل فئة: مجلد التطبيق، الاختصار، PATH للجهاز، عمليات التثبيت القديمة لكل مستخدم، التكوينات/ذاكرة التخزين المؤقت لكل مستخدم، ثم حزم Python المجمعة (TTS، PyTorch stack، Whisper+ctranslate2، Demucs، Wav2Lip deps، pyannote، أدوات خط الأنابيب)، وأخيرًا Python 3.11 وGit الاختياريين. |

**لا تتم الإزالة تلقائيًا مطلقًا:** أدوات إنشاء Visual Studio C++ (إذا كانت موجودة من عمليات التشغيل الأقدم). استخدم *التطبيقات والميزات* في إعدادات Windows لإزالتها يدويًا إذا رغبت في ذلك.

python video_translator_gui.py --preflight

يقوم بتشغيل تشخيصات البيئة المحلية دون بدء الترجمة أو تثبيت أي شيء. يتعامل `--preflight-lipsync` مع حزم وجه Wav2Lip كما هو مطلوب، وهو أمر مفيد قبل تمكين **Lip Sync**. تعرض واجهة المستخدم الرسومية نفس الفحص الأساسي من خلال زر **التشخيصات** بلوحة السجل. يتعامل `--preflight-player` مع مشغل الفيديو المدمج (python-mpv وlibmpv القابل للتحميل) كما هو مطلوب. يقوم `python -m videotranslator.libmpv_runtime check` باستكشاف libmpv وحده (الخروج 0 جاهز، 2 غير متاح).

### GUI

```bash
python video_translator_gui.py
```

**التخطيط:** توجد إعدادات الترجمة المجمعة في العمود الموجود على اليمين، كمجموعة من لوحات الإعدادات: **الإدخال**، **الترجمة**، **ملف تعريف سير العمل**، **البدء**، والأقسام المتقدمة القابلة للطي (النموذج، محرك الترجمة، الصوت، استنساخ الصوت، مزامنة الشفاه، تمييز المتحدثين، الخيارات، الكلمات المهمة). المنطقة الكبيرة على اليسار هي **مشغل الفيديو المدمج** (النقل، قائمة التشغيل، الصوت الأصلي A/B مقابل الصوت المدبلج، الترجمة، اللقطات، ملء الشاشة)، مع شريط **الترجمة الفورية** أسفله. اسحب البطاقة حسب عنوانها أو بواسطة المقبض **≡** لتحريكها لأعلى أو لأسفل العمود؛ يتم حفظ الطلب (`ui_panel_order`) واستعادته في البداية التالية. يمكن إخفاء لوحة السجل الموجودة في الأسفل باستخدام **إخفاء السجل**. عند البدء، يتم فتح النافذة في منتصف الشاشة الحالية (تحت المؤشر) ويتم تكبيرها، بحيث تعمل بشكل جيد في إعداد الشاشات المتعددة.

**عناصر التحكم في مشغل فيديو الفيديو:** تستخدم الرموز ألوانًا وظيفية متسقة في كل سمة، بغض النظر عن لون التمييز المحدد:

| السيطرة | اللون |
|---------|--------|
| تشغيل الفيديو | أخضر |
| إيقاف مؤقت (يستبدل التشغيل أثناء اللعب) | العنبر |
| إيقاف التشغيل | أحمر مرجاني |
| السابق / الخلفي 10 ثواني / الأمام 10 ثواني / التالي | أزرق |
| لقطة | البنفسجي |
| افتح المجلد | الذهب |

يضيف التحويم خلفية ملونة دقيقة. عناصر التحكم غير المتوفرة محايدة؛ يظل التنقل في قائمة التشغيل قابلاً للاستخدام بعد التوقف. تظل تلميحات الأدوات ومؤشرات تركيز لوحة المفاتيح متاحة، لذا فإن اللون ليس الطريقة الوحيدة لتحديد الإجراءات.

**من الملفات المحلية:**
1. انقر فوق **إضافة** لتحديد ملف فيديو واحد أو أكثر
2. اختر لغة المصدر واللغة المستهدفة
3. افتح قسم **النموذج** وحدد طراز Whisper (يعد `small` توازنًا جيدًا بين السرعة/الدقة)
4. اختر صوتًا واضبط سرعة TTS إذا لزم الأمر
5. *(اختياري)* في **محرك الترجمة** حدد **Google** (افتراضي)، **MarianMT** (محلي/غير متصل بالإنترنت)، **DeepL Free**، أو **Ollama LLM** (محلي، موصى به للدبلجة الصوتية)
6. *(اختياري)* تمكين **الاستنساخ الصوتي** (XTTS v2) و/أو **التعرف على الأشخاص المتحدثين (الكتابة)**
7. *(اختياري)* تمكين **مزامنة الشفاه** (Wav2Lip)
8. انقر **بدء الترجمة**

**من YouTube (أو أي موقع مدعوم):**
1. الصق عنوان URL واحدًا أو أكثر في الحقل **URL** (عنوان لكل سطر)
2. تكوين اللغة والنموذج والصوت كالمعتاد
3. انقر **⬇ تنزيل وترجمة**

> يدعم yt-dlp YouTube وVimeo وTwitter/X وTikTok و[أكثر من 1000 موقع آخر](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md).

> ⚠️ **إشعار الاستخدام العادل:** يعتبر تنزيل مقاطع الفيديو عبر yt-dlp بمثابة وصول تلقائي بواسطة منصات مثل YouTube وقد ينتهك شروط الخدمة الخاصة بها. يمكن أن يؤدي الاستخدام المكثف أو المتكرر من نفس عنوان IP إلى عمليات حظر مؤقتة (HTTP 429 / أخطاء مطلوبة لتسجيل الدخول). استخدم VPN أو قم بتدوير عنوان IP الخاص بك إذا واجهت فشلًا في التنزيل. هذه الأداة مخصصة للاستخدام الشخصي وغير التجاري فقط. قد تؤدي إعادة توزيع المحتوى المترجم إلى انتهاك حقوق الطبع والنشر - احترم دائمًا حقوق المنشئ الأصلي.

### الترجمة في الوقت الحقيقي (الترجمات والدبلجة الصوتية التجريبية)

شاهد ملفًا محليًا أو رابط فيديو تم حله عند الطلب مع ترجمات مترجمة وترجمة منطوقة اختيارية. استخدم الشريط الموجود أسفل المشغل:

**من الرابط:**

1. الصق رابطًا في الحقل **URL**
2. قم بتعيين لغة المصدر والهدف، واختر صوتًا واضبط شريط التمرير **التأخير**
3. حدد **الصوت المدبلج** و/أو **الترجمات**
4. لسماع الصوت المترجم فقط، حدد **كتم الصوت الأصلي** قبل البدء (باللغة الإيطالية: **Silenzia originale**، بجوار مربع اختيار الترجمة)
5. انقر **الترجمة في الوقت الفعلي** - تم حل الرابط وبدء الترجمة

**من ملف تم تحميله:** قم بتحميل مقطع فيديو في المشغل (الإدخال -> إضافة، ثم حدده)، واترك حقل عنوان URL فارغًا، واختر نفس الإعدادات المباشرة، وانقر على **ترجمة في الوقت الفعلي**. يأخذ عنوان URL الأولوية عندما لا يكون الحقل فارغًا.

- **المحرك:** MarianMT (غير متصل، افتراضي)، Google، DeepL، أو Ollama. يتم تشغيل التعرف على الكلام (Whisper) محليًا. تحتاج النماذج غير المتصلة بالإنترنت إلى تنزيل أولي.
- **الدبلجة الصوتية:** تشغيل تجريبي لخطاب Edge-TTS من خلال نسخة mpv ثانية. يتطلب الوصول إلى الإنترنت وهو منفصل عن استنساخ الصوت دفعة واحدة.
- **كتم الصوت الأصلي:** متاح قبل البدء وأثناء الترجمة. فهو يعمل على إسكات الموسيقى التصويرية الأصلية بأكملها، بما في ذلك الموسيقى والمؤثرات، لكنه يترك الصوت المترجم مسموعًا. لا يعزل الشخص المتحدث في الصوت الأصلي. قم بإيقاف تشغيله لاستعادة الموسيقى التصويرية؛ يتم إعادة تعيينه عند انتهاء الجلسة المباشرة. زر مكبر الصوت الخاص باللاعب هو زر كتم الصوت العام، وليس هذا التحكم المستقل.
- **إيقاف مؤقت والبحث:** عناصر التحكم في مشغل الفيديو متصلة بالجلسة المباشرة؛ لا تزال مزامنة الصوت من طرف إلى طرف بحاجة إلى اختبارات قبول خاصة بالمنصة.
- **الحدود الحالية:** تظل معالجة تداخل/تلاشي المقطع ومعايرة توقيت الصوت وقبول Windows مفتوحة. لا يتم دعم عمليات البث المباشر المتزايدة حتى الآن؛ لا تعني تسمية الوضع المباشر دعمًا لاستيعاب البث أثناء نموه. راجع [حالة التنفيذ والعمل المتبقي](../../docs/ACTION_PLAN.md#live-p5-handoff-to-claude-code-2026-09-26).

بالنسبة إلى مقطع فيديو مدبلج محفوظ، استخدم **التنزيل والترجمة** / **بدء الترجمة** بدلاً من المعاينة في الوقت الفعلي.

### كتل محرك الترجمة وVPN

يمكن أن يحدث كتلتان مختلفتان، مع إصلاحات مختلفة:

| كتلة | أعراض | إصلاح |
|-------|---------|-----|
| **تنزيل** (yt-dlp) | "قم بتسجيل الدخول للتأكد من أنك لست روبوتًا"، HTTP 429 | **VPN** / قم بتدوير IP، أو قم بتسجيل الدخول إلى YouTube في متصفحك (تتم قراءة ملفات تعريف الارتباط تلقائيًا) |
| **الترجمة** (نقطة النهاية المجانية من Google) | "تعذرت ترجمة Google Translate... معدل الطلب محدود/محظور" | استخدم **MarianMT** (غير متصل) أو **Ollama** (محلي) - لا يوجد حد لمعدل الطلب. تساعد شبكة VPN أيضًا. يعود تدفق الدُفعات الآن **إلى MarianMT تلقائيًا** عندما يتم حظر Google. |

### سطر الأوامر

| `--model` | موديل Whisper (`tiny` → `large-v3-turbo`) | `small` |
| `--tts-rate` | تعديل سرعة تحويل النص إلى كلام (على سبيل المثال `+10%`، `-20%`) | `+0%` |
| `--translation-engine` | `google` أو `marian` أو `deepl` | `google` |
| `--deepl-key` | مفتاح DeepL Free API | - |
| `--diarize` | تمكين التعرف على الأشخاص المتحدثين (تمييز المتحدثين) (pyannote) | - |
| `--hf-token` | رمز HuggingFace للتدوين | - |
| `--lipsync` | قم بتطبيق مزامنة الشفاه Wav2Lip بعد الدبلجة الصوتية | - |
| `--subs-only` | أنشئ `.srt` فقط، وتخطي الدبلجة الصوتية | - |
| `--no-subs` | تخطي جيل `.srt` | - |
| `--no-demucs` | تخطي فصل الصوت/الموسيقى | - |
| `--output` / `-o` | مسار ملف الإخراج | auto |
| `--output-dir` | مجلد للملفات المترجمة (مكان واحد، Windows وLinux) | `<videos>/VideoTranslatorAI` |
| `--batch` | معالجة ملفات متعددة | - |

### اختبارات التكامل مع النماذج الحقيقية

تتجنب مجموعة الاختبار الافتراضية تنزيلات النماذج الحقيقية وعمل GPU الطويل. لتشغيل اختبارات الاشتراك التجريبية للمكدس المحلي المثبت:

```bash
VTAI_RUN_HEAVY_SMOKE=1 python -m unittest discover -s tests -p "test_heavy_smoke.py" -v
```

تتحقق عمليات التحقق هذه من صحة واردات Wav2Lip الحقيقية، وتوافر Torch CUDA، وتوافر برنامج Ollama daemon، وfaster-Whisper على الكلام الاصطناعي. إنهم يفشلون أو يتخطون عمدا عندما تكون حالة برنامج التشغيل/البرنامج الخفي/النموذج المحلي غير جاهزة.

**أمثلة:**

```bash
# ترجمة الفيديو الإيطالي إلى الإنجليزية مع MarianMT المحلي
# (يتم تنزيل نموذج بسعة 298 ميجابايت تقريبًا عند الاستخدام الأول، ثم دون الاتصال بالإنترنت بالكامل)
python video_translator_gui.py video.mp4 --lang-source it --lang-target en --translation-engine marian

# الترجمة مع استنساخ الصوت + تحديد المتحدثين (تمييز المتحدثين)
python video_translator_gui.py interview.mp4 --lang-target en --diarize --hf-token hf_xxx

# ترجمة مع مزامنة الشفاه
python video_translator_gui.py video.mp4 --lang-target en --lipsync

# ترجمات فقط (بدون دبلجة صوتية)
python video_translator_gui.py video.mp4 --lang-target fr --subs-only
```

> يتم تنزيل النماذج تلقائيًا عند الاستخدام الأول.

## وحدات CLI للوحدة المستقلة

تكشف الحزمة المعيارية عن أربع أدوات تواجه المستخدم والتي يمكن استدعاؤها مباشرة دون تشغيل المسار الكامل:

```bash
# قم بالرحلة المسبقة لمقطع فيديو لحضور الوجه (سيتم تخطي Wav2Lip في حالة غيابه).
python3 -m videotranslator.face_detector path/to/video.mp4
# الخروج 0 = الوجه موجود، الخروج 1 = لا وجه

# تحليل ملف *_metrics.csv الذي تم إنتاجه بواسطة build_dubbed_track.
# تقارير P50/P75/P90/P95 من pre_stretch_ratio، انهيار نطاق السمع،
# استخدام المحرك الممتد، وأسوأ القيم المتطرفة مع النص المستهدف.
python3 -m videotranslator.metrics_csv path/to/video_metrics.csv

# تعقيم النص لتحويل النص إلى كلام (إعادة كتابة النقطتين، الفواصل المنقوطة، علامات الحذف، والشرطات).
echo "alle 10:30 ho detto: andiamo!" | python3 -m videotranslator.tts_text_sanitizer

# قم بتقدير صعوبة الدبلجة الصوتية من ملف المقاطع .srt أو .json قبل تشغيل TTS.
python3 -m videotranslator.difficulty_detector path/to/video_it.srt --target-lang it --expansion 1.25
```

تحتوي كل أداة على `-h`/`--help` للحصول على الخيارات الكاملة. وهي مستقلة بذاتها وتعيد استخدام نفس الوحدات التي يعتمد عليها مسار الدبلجة الصوتية، لذا يظل إنتاجها متسقًا مع وقت التشغيل.

### مكونات الطرف الثالث

رمز المستودع هو MIT. يقوم المثبتون بتنزيل المكونات أدناه من مصادرهم الخاصة في وقت التثبيت؛ المشروع لا يعيد توزيعها.

- **libmpv** (https://github.com/mpv-player/mpv)، محرك مشغل الفيديو المدمج. Windows: تمت تجربة إنشاء LGPL بواسطة zhongfly (https://github.com/zhongfly/mpv-winbuild) أولاً؛ يعد إنشاء GPL المثبت بواسطة shinchiro (https://sourceforge.net/projects/mpv-player-windows/files/libmpv/) هو الحل الاحتياطي. يسجل `mpv-runtime\BUILD.txt` المصدر ونكهة الترخيص والتزام mpv، ويوجد نص الترخيص بجوار ملف DLL. Linux: حزمة التوزيع (`libmpv2` أو `libmpv1` أو `mpv-libs` أو `mpv`).
- **FFmpeg** داخل libmpv (LGPL أو GPL، بعد إنشاء libmpv).
- **python-mpv** (`mpv` على PyPI)، GPLv2+ أو LGPLv2.1+.
- **7-Zip `7zr.exe`** 26.03 (LGPL)، يستخدمه مثبت Windows لاستخراج libmpv ويتم حذفه بعد ذلك.
- **محمل Vulkan** (Khronos، MIT وApache-2.0)، يتم تنزيله على نظام التشغيل Windows فقط في حالة فقدان `vulkan-1.dll`.
- **edge-tts** (LGPLv3)، يستخدم بواسطة مسار الدبلجة الصوتية.
- **نماذج MarianMT** (Helsinki-NLP)، التي تم تنزيلها من Hugging Face Hub عند الاستخدام لأول مرة بموجب تراخيصها الخاصة (Apache-2.0 لنماذج `opus-mt`، وCC-BY-4.0 لـ `opus-mt-tc-big`).
